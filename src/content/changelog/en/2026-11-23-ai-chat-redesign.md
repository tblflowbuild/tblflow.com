- **Better-rendered answers**: tables and code with syntax highlighting and a copy button; a table can be copied as CSV, Markdown or TSV.
- **A thread that follows the answer**: it stays at the bottom while the answer is written, detaches as soon as you scroll up to read, and a “Back to bottom” button appears.
- **Visible work**: the AI shows what it is doing, with a timer and each tool it uses, then folds it all into “Worked 12 s · 4 steps”. Building a complete application becomes a readable list of steps.
- **Proposals you can decline**: every proposal (table, field, automation…) has a “Decline” button next to “Accept” and folds into one line once handled.
- **Reasoning level**: a “Reasoning” menu offers Fast, Normal or Deep. Deep is reserved for the Team and Enterprise plans and uses more credits.
- **Model matched to the request**: the chat can classify each request and send it to the model that fits, which makes your AI credits last longer. Administrators set the mode in the AI settings.
- **Calmer input and a more reliable stream**: a quiet input frame, cancelling an answer in progress, and better-handled limits and timeouts.
