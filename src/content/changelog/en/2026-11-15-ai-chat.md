- **A question gets an answer**: until a target is chosen, the chat exposes no write tool. After a table is created, the interface is no longer offered by default; it becomes a clickable suggestion.
- **Readability**: an answer fits in a single bubble, Markdown tables display, tables and code scroll, and a button copies the answer. Scrolling follows the bottom only if you are already there.
- **Cut-offs flagged**: if the answer stops midway, the chat shows an error and a Retry button. A warning appears when the answer is cut off by its length.
- **History**: it now reopens a base's conversations.
- **Connectors**: the chat can read your connectors (read-only lists) and propose filling a table, which you accept or decline.
