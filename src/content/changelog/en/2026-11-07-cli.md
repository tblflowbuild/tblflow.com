The **TblFlow CLI** is published on npm: `npm install -g @tblflow/cli`. It requires Node.js 20 or later, has no third-party dependencies and collects no telemetry.

- **Device-code sign-in** on your machine (`tblflow login`), or with a **service token** in continuous integration (the `TBLFLOW_TOKEN` variable, never written to disk).
- **Records**: list, read, create, edit, delete (preview, then trash with `--confirm`).
- **CSV**: `tblflow import` adds a CSV's rows to a table, `tblflow import --new-table` creates a table from a CSV, `tblflow export` exports a table or a view.
- **Automations and agents**: run the ones their owner has exposed.
- **Local MCP server**: `tblflow mcp serve` connects an MCP client on your machine (Claude Code, Cursor…) to your bases.

Guide: [TblFlow CLI](/en/docs/cli). Announcement: [the TblFlow CLI](/en/blog/tblflow-cli). For Claude with nothing to install, see the [MCP server](/en/mcp).
