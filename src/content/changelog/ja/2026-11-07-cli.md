**TblFlow CLI**をnpmで公開しました：`npm install -g @tblflow/cli`。Node.js 20以上が必要で、サードパーティの依存関係はなく、テレメトリーも収集しません。

- **デバイスコードでの接続**はお使いのパソコンで行います（`tblflow login`）。継続的インテグレーションでは**サービストークン**を使います（環境変数 `TBLFLOW_TOKEN`。ディスクには書き込まれません）。
- **レコード**：一覧表示、読み取り、作成、編集、削除（プレビューのあと、`--confirm` でごみ箱へ）。
- **CSV**：`tblflow import` はCSVの行をテーブルに追加し、`tblflow import --new-table` はCSVからテーブルを作成し、`tblflow export` はテーブルまたはビューをエクスポートします。
- **自動化とエージェント**：所有者が公開したものを実行できます。
- **ローカルMCPサーバー**：`tblflow mcp serve` で、お使いのパソコンのMCPクライアント（Claude Code、Cursorなど）をベースに接続します。

ガイド：[TblFlow CLI](/ja/docs/cli)。お知らせ：[TblFlow CLI](/en/blog/tblflow-cli)。インストール不要でClaudeを使うには、[MCPサーバー](/ja/mcp)をご覧ください。
