L'arrivée dans TblFlow est repensée pour aller vite vers quelque chose d'utile.

- **L'IA d'abord** : collez la clé de votre fournisseur, elle est testée sur place et les modèles sont choisis pour vous. Un guide en trois étapes aide à obtenir une clé. Vous pouvez aussi passer et y revenir plus tard.
- **Votre entreprise en quelques questions** : services, outils, et, si vous le souhaitez, vos procédures existantes (PDF, Markdown, texte ou Word) déposées dans la bibliothèque de documents.
- **Une carte des process préremplie** avec les services et les outils que vous avez déclarés, puis une première application générée.
- **Une liste « Premiers pas »** pour finir l'installation : IA, marque, organigramme, notifications, recherche web, carte des process, première application, procédures. Elle se masque quand vous n'en avez plus besoin.

Un membre invité dans un espace existant saute ces étapes et arrive directement dans l'espace.
