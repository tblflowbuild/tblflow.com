Le **CLI TblFlow** est publié sur npm : `npm install -g @tblflow/cli`. Il demande Node.js 20 ou plus, n'a aucune dépendance tierce et ne collecte aucune télémétrie.

- **Connexion par code appareil** sur votre poste (`tblflow login`), ou par **jeton de service** en intégration continue (variable `TBLFLOW_TOKEN`, jamais écrite sur le disque).
- **Enregistrements** : lister, lire, créer, modifier, supprimer (aperçu, puis corbeille avec `--confirm`).
- **CSV** : `tblflow import` ajoute les lignes d'un CSV à une table, `tblflow import --new-table` crée une table depuis un CSV, `tblflow export` exporte une table ou une vue.
- **Automatisations et agents** : lancez ceux que leur propriétaire a exposés.
- **Serveur MCP local** : `tblflow mcp serve` branche un client MCP de votre poste (Claude Code, Cursor…) sur vos bases.

Guide : [CLI TblFlow](/fr/docs/cli). Annonce : [le CLI TblFlow](/fr/blog/cli-tblflow). Pour Claude sans installation, voir le [serveur MCP](/fr/mcp).
