La **CLI di TblFlow** è pubblicata su npm: `npm install -g @tblflow/cli`. Richiede Node.js 20 o superiore, non ha alcuna dipendenza di terze parti e non raccoglie alcuna telemetria.

- **Accesso con codice dispositivo** sul tuo computer (`tblflow login`), o con **token di servizio** in integrazione continua (variabile `TBLFLOW_TOKEN`, mai scritta su disco).
- **Record**: elencare, leggere, creare, modificare, eliminare (anteprima, poi cestino con `--confirm`).
- **CSV**: `tblflow import` aggiunge le righe di un CSV a una tabella, `tblflow import --new-table` crea una tabella da un CSV, `tblflow export` esporta una tabella o una vista.
- **Automazioni e agenti**: avvia quelli che il loro proprietario ha esposto.
- **Server MCP locale**: `tblflow mcp serve` collega un client MCP del tuo computer (Claude Code, Cursor…) alle tue basi.

Guida: [CLI di TblFlow](/it/docs/cli). Annuncio: [la CLI di TblFlow](/en/blog/tblflow-cli). Per Claude senza installazione, vedi il [server MCP](/it/mcp).
