La **CLI de TblFlow** está publicada en npm: `npm install -g @tblflow/cli`. Requiere Node.js 20 o superior, no tiene ninguna dependencia de terceros y no recopila ninguna telemetría.

- **Conexión con código de dispositivo** en tu equipo (`tblflow login`), o con **token de servicio** en integración continua (variable `TBLFLOW_TOKEN`, nunca escrita en disco).
- **Registros**: listar, leer, crear, modificar, eliminar (vista previa y después papelera con `--confirm`).
- **CSV**: `tblflow import` añade las filas de un CSV a una tabla, `tblflow import --new-table` crea una tabla a partir de un CSV y `tblflow export` exporta una tabla o una vista.
- **Automatizaciones y agentes**: lanza los que su propietario ha expuesto.
- **Servidor MCP local**: `tblflow mcp serve` conecta un cliente MCP de tu equipo (Claude Code, Cursor…) a tus bases.

Guía: [CLI de TblFlow](/es/docs/cli). Anuncio: [la CLI de TblFlow](/en/blog/tblflow-cli). Para Claude sin instalar nada, consulta el [servidor MCP](/es/mcp).
