- **Canvas**: F2 justo después de cerrar la ficha mantiene el campo de nombre.
- **Panel «Por planificar»**: el Gantt se actualiza sin recargar y el calendario muestra el fin calculado.
- **Arrastrar desde «Por planificar»**: se conserva la fecha de fin.
- **Tiempo real**: una actualización de varios campos de una fila llega de una sola vez a tus colaboradores.
- **Asientos**: el número de asientos se comprueba al cambiar un rol.
- **Eliminación de un campo**: la vista previa ya no muestra las tablas que no tienes permiso para leer.
