Das **TblFlow-CLI** ist auf npm veröffentlicht: `npm install -g @tblflow/cli`. Es benötigt Node.js 20 oder höher, hat keine Abhängigkeiten von Drittanbietern und erhebt keinerlei Telemetrie.

- **Anmeldung per Gerätecode** auf Ihrem Rechner (`tblflow login`) oder per **Service-Token** in der Continuous Integration (Variable `TBLFLOW_TOKEN`, nie auf die Festplatte geschrieben).
- **Datensätze**: auflisten, lesen, anlegen, ändern, löschen (Vorschau, dann Papierkorb mit `--confirm`).
- **CSV**: `tblflow import` fügt die Zeilen einer CSV-Datei einer Tabelle hinzu, `tblflow import --new-table` legt eine Tabelle aus einer CSV-Datei an, `tblflow export` exportiert eine Tabelle oder eine Ansicht.
- **Automatisierungen und Agenten**: Starten Sie die, die ihr Eigentümer freigegeben hat.
- **Lokaler MCP-Server**: `tblflow mcp serve` verbindet einen MCP-Client auf Ihrem Rechner (Claude Code, Cursor …) mit Ihren Bases.

Anleitung: [TblFlow-CLI](/de/docs/cli). Ankündigung: [das TblFlow-CLI](/en/blog/tblflow-cli). Für Claude ohne Installation siehe den [MCP-Server](/de/mcp).
