**TblFlow CLI** 已发布在 npm 上：`npm install -g @tblflow/cli`。它需要 Node.js 20 或更高版本，没有任何第三方依赖，也不收集任何遥测数据。

- **设备码登录**：在您的电脑上使用 `tblflow login`；在持续集成中则使用**服务令牌**（环境变量 `TBLFLOW_TOKEN`，绝不写入磁盘）。
- **记录**：列出、读取、创建、修改、删除（先预览，加上 `--confirm` 后进入回收站）。
- **CSV**：`tblflow import` 将 CSV 的行追加到数据表，`tblflow import --new-table` 从 CSV 创建数据表，`tblflow export` 导出数据表或视图。
- **自动化与智能体**：运行其所有者已开放的自动化和智能体。
- **本地 MCP 服务器**：`tblflow mcp serve` 将您电脑上的 MCP 客户端（Claude Code、Cursor 等）连接到您的数据库。

指南：[TblFlow CLI](/zh/docs/cli)。公告：[TblFlow CLI](/en/blog/tblflow-cli)。无需安装即可使用 Claude，请参见 [MCP 服务器](/zh/mcp)。
