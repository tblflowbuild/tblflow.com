**TblFlow CLI** опубликован в npm: `npm install -g @tblflow/cli`. Ему нужен Node.js 20 или новее, у него нет сторонних зависимостей, и он не собирает телеметрию.

- **Вход по коду устройства** на вашем компьютере (`tblflow login`) или по **сервисному токену** в непрерывной интеграции (переменная `TBLFLOW_TOKEN`, никогда не записывается на диск).
- **Записи**: просмотр списка, чтение, создание, изменение, удаление (предварительный просмотр, затем корзина с `--confirm`).
- **CSV**: `tblflow import` добавляет строки из CSV в таблицу, `tblflow import --new-table` создаёт таблицу из CSV, `tblflow export` экспортирует таблицу или представление.
- **Автоматизации и агенты**: запускайте те, которые открыл их владелец.
- **Локальный MCP-сервер**: `tblflow mcp serve` подключает MCP-клиент на вашем компьютере (Claude Code, Cursor…) к вашим базам.

Руководство: [TblFlow CLI](/ru/docs/cli). Анонс: [TblFlow CLI](/en/blog/tblflow-cli). Для Claude без установки см. [MCP-сервер](/ru/mcp).
