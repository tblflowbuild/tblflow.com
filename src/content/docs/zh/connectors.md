连接器将 TblFlow 与外部服务相连：一个账户（Gmail、Slack……）、一个通过密钥访问的 API，或一个 PostgreSQL 数据库。您的字段、数据表、自动化和智能体随后都可以使用它。

## 在哪里找到它们

在数据库中打开 **自动化**，然后进入 **连接器** 标签页。共有两个视图：

- **我的**：已连接的账户、API 和数据库；
- **发现**：可以添加的内容，支持搜索和分类（消息、CRM、办公效率等）。

**用 AI 创建** 按钮可根据 API 的文档创建连接器。本页不介绍该功能。

## 连接

### 账户（OAuth）

在 **发现** 中，点击服务旁边的 **+** 按钮（提示为「连接」加服务名称）：服务方的窗口随即打开，用于授权您的账户。您可以填写 **账户名称** 以便识别。之后，连接器面板中会出现 **重新连接** 和 **断开连接**。断开连接会停止所有使用该账户的内容（自动化、字段、智能体），直到重新连接为止。

如果服务器尚未为某项服务配置 OAuth 应用，该服务会显示在 **未配置（管理员）** 下。此时，空间管理员可以在连接窗口的 **高级** 区域中填写其组织的 OAuth 应用。

### 通过密钥连接的 API

API 连接器位于 **发现** 的 **目录** 部分。API 连接器需要先安装（**安装**），然后连接（**连接**）：粘贴您的密钥，如果需要，还要填写账户地址。TblFlow 会立即验证密钥是否有效。

**使用的账户** 设置可在 **共享账户**（整个空间共用）和 **每位用户的账户** 之间选择。使用共享账户时，所有调用都通过同一个账户进行，该账户由空间的管理者连接。

### PostgreSQL 数据库

**PostgreSQL** 连接器以只读方式读取现有数据库中的数据表。不会发送任何写入请求。

## 功能

连接器面板会列出 **功能**。每项功能属于以下三类之一：

| 类别 | 含义 |
|---|---|
| **读取** | 根据一个值读取一条记录 |
| **列出** | 返回一组项目 |
| **执行** | 在服务中创建、修改或发送某些内容 |

**测试** 按钮可在面板中试运行某项功能。之后，一项功能可在四个位置使用（**使用位置** 部分）：已连接的字段、同步表、自动化（**调用功能** 步骤），或智能体（智能体可将功能作为工具调用）。

对于从目录安装的连接器，**允许写入** 设置默认关闭。关闭时，在服务中创建、修改或删除内容的功能在各处都会被拒绝（自动化、按钮、智能体）；读取类功能仍可使用。

## 同步到数据表

同步表会从服务导入一个列表，并持续保持更新：每个项目成为一行。

1. 启用连接器，打开其面板，在 **使用位置** 部分点击 **同步表**。
2. 选择数据库，然后点击 **创建同步表**。
3. 选择 **连接器** 和 **列表**（返回列表的功能）。**预览** 会显示前几个项目。
4. 勾选 **列**（类型：文本、长文本、数字、复选框、日期、链接、电子邮件），并选择 **唯一标识符**，用于在每次同步之间识别同一个项目。
5. 设置 **同步** 频率：每 15 分钟、每小时、每 6 小时、每天，或手动。
6. 选择 **已消失的项目** 的处理方式（**保留行** 或 **删除行**）、**最大项目数** 和 **模式**，然后点击 **创建数据表**。

**增量** 模式只重新读取上次同步后有变化的项目，默认每 7 天重新读取一次完整列表。只有当连接器为该列表声明支持时才可使用此模式。**完整** 模式每次都会重新读取整个列表。若未另行设置，读取在 5 000 个项目时停止；可设置的最大值为 50 000。一个同步表最多有 100 列。若读取因此被中止，会显示提示信息。

数据表的 **同步** 菜单可查看状态，并提供 **立即同步**、**全部重新同步** 和 **停止同步**（数据表及其行会保留）。

默认情况下，数据表为只读。选项 **将更改回传至 API** 可选择 **经数据库管理员批准后** 或 **每次修改后自动回传**；此选项要求该连接器已允许写入。

## 触发自动化：「新项目」

在 [自动化](/zh/docs/automations) 中，**连接器中出现新项目** 触发器会针对列表中的每个新项目各运行一次自动化。

- 选择连接器、一个项目带有标识符的列表、其参数，以及 **检查** 频率：15 分钟、1 小时、6 小时或 1 天。
- 首次读取会记住已存在的项目，但不会运行任何内容。只有之后出现的项目才会触发自动化。
- 项目的字段可通过 `{{item.<路径>}}` 读取。
- 每次读取最多运行 50 次，最多翻阅 5 页。

## 发现中提供的连接器

### 账户（OAuth）

| 账户 | 连接器面板中显示的功能 |
|---|---|
| Gmail | 搜索和读取电子邮件，发送电子邮件 |
| Google 日历 | 列出事件，创建事件 |
| Google 云端硬盘 | 搜索文件，读取文件信息 |
| Google Meet | 创建会议链接 |
| Google Chat | 列出空间，发布消息 |
| Slack | 列出频道，读取频道消息，发送消息 |
| GitHub | 列出和读取 issue，创建 issue，列出拉取请求，发表评论 |
| Outlook | 列出电子邮件，发送电子邮件 |
| Microsoft Teams | 列出您的团队及其频道，读取、发布和回复，创建会议 |
| Discord | 读取您的个人资料，列出您的服务器 |

### 通过密钥连接的 API

| 连接器 | 功能 | 需要提供 |
|---|---|---|
| Make | 读取您的组织、团队和场景、其状态及蓝图（只读） | Make API 令牌（权限范围 `scenarios:read` 和 `teams:read`）以及您所在区域的地址 |
| n8n | 读取您的工作流及其执行记录，适用于 n8n Cloud 实例 | n8n API 密钥以及您的实例地址 |
| HubSpot | 读取、搜索、创建和更新联系人、公司及交易，并关联它们 | HubSpot 私有应用的令牌 |

Make、n8n 和 HubSpot 也可用于 [流程图](/zh/docs/process-map)。

### ClickUp（尚未在发现中提供）

ClickUp 连接器已经开发完成，但仍在真实账户上进行验收测试：它不会出现在 **发现** 中，因为其中只显示已发布的连接器。界面中也没有安装它的按钮。在正式发布之前，请不要将其用于日常工作。

它使用 ClickUp **个人令牌** 进行连接（令牌以 `pk_` 开头）。连接指南会说明在哪里生成该令牌：在 ClickUp 中，点击您的头像，进入 **设置**，然后进入 **应用**，在 **API 令牌** 部分。该令牌没有权限范围：它以您本人的权限运行，可访问您有权限的所有工作区。如需限制访问范围，请仅在必要的工作区中使用访客账户生成该令牌。

| 类别 | 功能 |
|---|---|
| **列出** | 工作区；某工作区中的空间；某空间中的文件夹；某文件夹中的列表；直接位于空间中、不属于任何文件夹的列表；某列表中的任务；某列表的成员 |
| **读取** | 一个任务，包括其自定义字段，以及（如需要）其子任务 |
| **执行** | 在某列表中创建任务；修改任务或将其归档（仅更改您发送的字段，此处不修改自定义字段）；为任务添加评论 |

以上三项执行类功能属于写入操作：在 **允许写入** 设置关闭时会被拒绝，与目录中的其他连接器相同。列表中的任务按每页 100 条读取，默认最新的优先。

TblFlow 会对 ClickUp 的调用进行节流：同时最多 2 个，两次调用之间至少间隔 600 毫秒。这一速率仍低于 ClickUp 在其最低档套餐上施加的限制，即每个令牌每分钟 100 个请求。

**连接器中出现新项目** 触发器（见上文）可与 **列出列表中的任务** 功能配合使用：ClickUp 列表中每出现一个新任务，自动化即会运行一次。

## 所需权限

| 操作 | 空间角色 |
|---|---|
| 使用连接器，连接自己的账户 | 所有角色 |
| 创建和修改连接器 | 所有者、创建者、编辑者 |
| 从目录安装 | 所有者；若安装不受限制，则创建者也可以 |
| 删除连接器 | 所有者、创建者 |

目录的管理方式在空间中设置：**自由（空间所有者和创建者）** 或 **需空间管理员批准**。在第二种情况下，其他成员使用 **请求安装**。

创建同步表需要在数据库中创建数据表的权限。各角色的权限详见 [权限与角色](/zh/docs/permissions)。

## 调用配额

每个套餐对每月的 API 连接器真实调用次数设有上限（由缓存提供的响应不计入）：免费版 1 000 次，Essential 50 000 次，团队版 500 000 次。详见 [套餐与限制](/zh/docs/plans-limits)。
