本页汇总了哪些内容可以导入 TblFlow、哪些内容可以导出，以及如何撤回操作。

## 导入文件

TblFlow 支持三种格式：**CSV**、**TSV** 和 **Excel**（扩展名为 `.xlsx`、`.xls` 和 `.xlsm`）。对于本地文件，系统根据扩展名识别格式。从您的电脑上传的 Excel 文件不能超过 5 MB。

根据您想新建数据表还是向现有数据表添加记录，有两个入口。

### 导入为新数据表

1. 在数据库的侧边栏中，打开 **+** 菜单，进入 **从其他来源添加** 类别，然后点击 **导入数据**。
2. 选择 **本地文件** 标签（将文件拖入区域）或 **链接（URL）** 标签（粘贴文件地址）。
3. **数据预览** 会显示检测到的列。您可以开启 **用 AI 分析并实现**：AI 会建议列名和字段类型，您可以在下一步保留或修改。
4. 设置导入选项：
   - **将第一行用作表头**；
   - **自动选择字段类型**；
   - 每个字段的名称和类型，或选择 **不导入** 以排除某一列；
   - **主字段**；
   - **导入数据**（取消勾选则只创建结构）；
   - 对于 Excel 工作簿，按工作表逐个配置（**工作表名称**）。
5. 点击 **导入**，然后在警告消息中点击 **确认并继续**。

字段名称必须唯一且不能为空。导入只会以成功或失败结束：其状态显示在数据表右上角，并通过通知告知结果。导入期间请避免修改字段。

### 导入到现有数据表

打开数据表的菜单，点击 **导入数据**，然后选择 **CSV 文件** 或 **Microsoft Excel**。将文件的每一列与数据表的一个字段对应，并可勾选 **导入时排除第一行**。记录会追加到已有记录之后。

此操作需要向数据表导入数据的权限：所有者和创建者角色。通过导入创建新数据表则需要创建数据表的权限。

### 限制和错误

导入受您套餐中每个数据表行数上限的约束：免费版为 5 000 行，基础版为 100 000 行，团队版为 1 000 000 行，企业版不设上限。超出上限时，导入会停止并显示“已达到行数上限”。参见[套餐和限制](/zh/docs/plans-limits)。

其他可能的错误：日期超出有效范围、**必填** 字段留空、在只接受 **唯一值** 的字段中出现重复值，或超时。

### 其他导入方式

- **粘贴到表格中。** 从电子表格复制单元格，然后粘贴到表格视图中。如果粘贴内容超出数据表范围，TblFlow 会询问是否添加记录；在覆盖现有记录之前，它也会要求您确认。
- **命令行：** `tblflow import --new-table` 用于上传 CSV 文件。参见 [CLI](/zh/docs/cli)。
- **通过智能体：** MCP 服务器提供 `import_csv` 工具。参见 [MCP 服务器](/zh/docs/mcp-server)。

## 导出

### 将数据表导出为 CSV

在数据表菜单中点击 **下载 CSV**。在表格视图中，可以通过标签页菜单（右键点击）使用同样的选项：此时导出会基于该视图，并保留其筛选和排序。所有可以读取该数据表的角色都可以导出。

### 导出整个数据库

在空间的数据库列表中，数据库菜单提供 **导出**。**导出** 窗口提供 **包含记录** 选项：关闭时，只导出结构和配置。

1. 点击 **开始导出**。导出可能需要一些时间；您可以关闭窗口。
2. 通知会告知数据已准备就绪。
3. 点击 **下载** 获取 `.tbl` 文件。

要重新导入，请将 `.tbl` 文件拖放到空间页面：“拖放您的 .tbl 文件以导入”。导出时，指向其他数据库的链接字段会被转换为单行文本。

导出或复制数据库需要修改该数据库的权限：所有者和创建者角色。

## 撤销和重做

工具栏中的 **撤销** 和 **重做** 按钮（快捷键 Ctrl 或 Cmd + Z，以及 Ctrl 或 Cmd + Shift + Z）可以撤销或重做您对数据表的最近操作。只有在您能够修改记录时，这些按钮才可用。

涵盖的操作包括：输入和粘贴单元格内容、创建、删除和重新排序记录、创建、删除和转换字段，以及创建、修改和删除视图。

撤销历史按每个人、每个数据表分别保存。默认保留最近 200 个操作，时长 24 小时。新的操作会清空重做栈。

**记录历史** 是另一个工具：它记录谁修改了什么，并保存修改前后的值。参见[视图、筛选和记录卡片](/zh/docs/views-and-filters)。

## 回收站

删除数据表、数据库、记录、字段或视图时，并不会立即彻底删除：该项目会进入回收站，您可以在那里 **恢复**。

| 回收站 | 位置 | 包含内容 |
|---|---|---|
| **数据表回收站** | 数据表菜单 | 已删除的视图、字段和记录 |
| **数据库回收站** | 数据库侧边栏中的 **回收站** 图标 | 已删除的数据表、应用、自动化、智能体和浏览器技能 |
| **空间回收站** | 空间菜单 | 该空间中已删除的数据库 |
| **空间回收站** | 空间选择器 | 已删除的空间、数据库和数据表，分为三个标签页 |

**类型**、**删除人** 和 **日期** 列显示删除的内容、删除人和删除时间；在数据表回收站中，**起始** 和 **截止** 筛选器可限定时间范围。**空间回收站** 页面还提供 **永久删除**。

- **保留期限。** 默认为 30 天。超过该期限后，自动清理会永久删除该项目。数据库回收站和空间回收站会显示您实例适用的保留期限（“在最近 N 天内删除”）。
- **清空** 在确认后会永久删除数据库回收站中的全部内容。
- **配额。** 回收站中的数据仍计入您的记录和附件用量。
- **恢复顺序。** 如果某项目的上级项目本身也在回收站中，则无法单独恢复它：请先恢复数据库，再恢复其数据表。
- **字段。** 恢复字段会还原其数值。由于操作可能涉及大量记录，会显示进度窗口。

只有所有者、创建者和编辑者角色可以查看和恢复数据表的回收站。评论者和读者角色无权访问。参见[权限和角色](/zh/docs/permissions)。

## 复制数据表或数据库

**数据表。** 打开数据表菜单，点击 **复制**。为副本命名，并选择是否复制记录（默认开启 **包含记录**）。您需要能够读取该数据表，并能在该数据库中创建数据表：所有者和创建者角色。

**数据库。** 打开数据库菜单，点击 **复制**，然后点击 **复制数据库**。选择目标空间，并决定是否复制记录。您的修订历史和协作者不会被复制。

## 从模板开始

模板是即开即用的数据库。选择模板后，**从模板创建数据库** 窗口会要求选择目标空间，并提供 **复制记录** 选项：开启时，数据库会保留模板的示例数据；关闭时，只复制结构。您需要有权在所选空间中创建数据库。

如需发布您自己的模板，参见[分享和发布](/zh/docs/sharing-publishing)。
