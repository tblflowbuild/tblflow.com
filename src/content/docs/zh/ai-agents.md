智能体是附属于某个数据库的执行者。它有指令、一组工具和记忆，默认情况下，它的每一次写入都要等待您的同意。

智能体的配置页分为五个标签页：**指令**、**任务**、**技能**、**知识**和**记忆**。

## 选择模型

模型提供商及其密钥按空间配置，位于 **空间 AI 设置** 中。只有空间所有者可以修改。密钥在存储时加密，保存后不再以明文显示。

可用的提供商包括：OpenAI、Anthropic、Google、Azure、Cohere、Mistral、DeepSeek、xAI、Amazon Bedrock、OpenRouter、任何兼容 OpenAI 的端点，以及通过 Ollama 和 LM Studio 运行的本地模型。您添加的密钥与实例自带的密钥叠加使用，除非您关闭 **默认使用实例模型**。

在智能体的配置页中，**模型** 选择器可以为它指定专属模型。若不选择，智能体使用 AI 配置中默认的聊天模型。

## 界定范围

智能体的范围由三部分决定。

- **它的数据库。** 智能体不能读取或写入其他数据库中的数据表：不在其数据库中的数据表会被拒绝访问。
- **它的工具。** **技能** 标签页列出智能体可以执行的操作。被关闭的工具不会提供给模型，因此模型无法调用它。大多数针对记录、数据表和评论的工具默认开启。涉及外部服务或生成文件的工具默认关闭，需逐个开启：网页搜索、生成 Excel、Word、PowerPoint 和 PDF 文件、执行技能或代码、邮件、Slack、Microsoft Teams、GitHub、日历、Drive 和 SharePoint，以及重放浏览器技能。委派给其他智能体的功能仅对编排型智能体默认开启。
- **它的连接。** 在 **连接器** 中连接的账户供您的智能体使用。当没有人启动智能体时（定时或触发器），使用的是其创建者的账户。您也可以为智能体添加 MCP 服务器。

若要限制智能体能够触及的范围，请移除它不需要的工具。负责客服分流的智能体没有理由发送邮件或删除记录。

## 写入校验

**写入校验** 设置默认开启，逐个智能体设置。开启期间，具有实际影响的工具不会直接执行：智能体会暂停并请求您的批准。涉及的操作包括：创建、修改和删除记录，创建数据表、字段和视图，评论，发送邮件或消息，启动自动化，执行代码或技能，以及写入记忆。

您可以回复 **批准** 或 **拒绝**（可附带可选的理由）。待处理的请求会出现在数据库的 **审批** 页面中，可通过 **查看待审批事项** 链接打开。如果一直没有回复，请求将在 7 天后过期，操作不会被执行。

只有在观察到智能体的错误之后，才应关闭此设置。关闭后，智能体将自行写入所有内容：该设置不能逐个数据表设置。

## 记忆

**记忆** 标签页可开启或关闭智能体的记忆，记忆包含两个部分：

| 部分 | 内容 |
| --- | --- |
| 最近 | 近期工作中的短期记忆，保留 7 天；最多保留最新的 50 条，并在任务开始时向智能体提供最新的 5 条 |
| 偏好 | 人类给出的指令，以键和值的形式保存，在每个任务中都会提供给智能体 |

当智能体记住某些信息时，其中的实体和关系可能会被提取到空间图谱中，智能体通过 **搜索记忆** 工具进行查询。因此，记忆并非对话历史：对话内容单独保存在历史记录中。

**查看记忆** 会打开智能体的记忆列表。数据库编辑者可以 **修正** 或 **删除** 某条记忆：如果智能体记住了错误的内容，应修正该条目，而不是修改指令。

## 技能

技能是一组有名称的指令，可以附带一个脚本，供智能体使用。技能可以是个人的（归账户所有），也可以在空间中共享。智能体可用的技能包括其创建者的技能以及空间中的技能；每个技能默认关闭，需要在智能体的 **技能** 标签页中为其开启。技能脚本的执行通过 **执行技能脚本** 工具进行，该工具同样默认关闭。

## 触发器

**任务** 标签页显示智能体何时运行。

| 触发器 | 运行方式 |
| --- | --- |
| 提及 | 在某条记录上提及智能体时，它会进行分析并回复（开关） |
| 私信 | 智能体回复发给它的消息（开关） |
| **运行智能体** | 按需手动执行 |
| 定时 | 按周期性时间表运行，或按自定义 cron 表达式运行；间隔小于 15 分钟的设置默认会被拒绝 |
| 自动化 | 在某个数据表中创建或修改记录时触发 |
| 传入 Webhook | 由一次 HTTP 调用触发智能体 |

记录触发器只有在关闭写入校验时才会生效：只要写入校验处于要求状态，它就保持不活动，因为自动触发时无法向人类请求批准。定时和 Webhook 触发器则可以配合写入校验使用：批准请求会出现在审批中。

## 配额

每次智能体运行都会计入当月配额，无论是手动启动、定时运行还是被触发。

| 套餐 | 每月智能体运行次数 |
| --- | --- |
| 免费版 | 100 |
| Essential | 5 000 |
| 团队版 | 50 000 |
| 企业版 | 无限制 |

在自托管部署中，这些上限不会生效。此外，AI 的使用还受套餐所规定的其他限制。[自动化](/zh/docs/automations) 的配额单独计算。

## 历史记录

每次运行都会作为一段对话保存下来，包括智能体的工具调用、参数和结果。您可以在智能体的聊天界面中查看对话历史。

## 最佳实践

- 每个智能体只承担一个目标。一个“负责整个 CRM”的智能体会以模糊的方式出错；三个职责单一的智能体则会以清晰可读的方式出错。
- 起初保持写入校验开启，只有在看清它出错的性质之后才将其关闭。
- 只开启智能体任务所必需的工具。
