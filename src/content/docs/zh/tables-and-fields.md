TblFlow 的数据表就是真正的 PostgreSQL 表，字段就是真正的列。正因如此，即使您从不离开界面，本页也同样有用：您在这里的选择，就是数据库中真实存在的内容。

## 字段类别

**类型**菜单提供 28 种字段类型，另外还有两个条目：**查找**和**条件查找**。字段类型不取决于您的版本等级。

**简单值** — 单行文本、长文本、邮箱、电话、URL、数字、日期、复选框、评分。它们只存储您输入的内容，不多不少。邮箱、电话和 URL 会强制要求有效格式。

**时长** — 时长（可显示为 1:30、1:30:00 或 1h 30m），以及跟踪时长（按人员、按行记录每个人花费的时间）。

**跟踪时长。** 单元格显示总时长，以小时和分钟为单位；字段设置中的**显示秒数**选项会加上秒。单元格中无需输入任何内容：双击（或按回车），或打开记录详情，即可进入计时器。**开始**启动一个时段，**停止**结束它；计时期间，显示的总时长每秒递增，字段值在停止时更新。时段按人员列出，并显示开始时间。每个人只能删除自己的时段（**删除此时段**），总时长随之重新计算。每人、每行、每个字段同一时间只能有一个进行中的时段。开始和停止计时器需要编辑记录的权限；只有只读角色时，总时长和时段仍可见，但不显示该按钮。

**受限值** — 单选、多选、用户。选项在字段级别定义。

**关系** — 关联记录、查找、汇总、条件查找、条件汇总。见下文。

**计算** — 公式（200 多个函数）、自动编号、行 ID、创建时间、最后修改时间、创建者、最后修改者。它们不能手动输入。

**资产** — 附件、按钮、AI 字段、Canvas。AI 字段根据其他字段生成单元格内容。Canvas 字段会为每一行在文档库中创建一份文档。

**格式。** 货币和百分比不是独立的类型：它们是**数字**类型的格式，与**环形**和**条形**一样，只是显示同一个数值的两种方式。同样，**日期**和**日期和时间**是**日期**类型的两种设置。

数据表的主字段用于标识每条记录，它只接受部分类型：例如不接受附件，也不接受关联记录。

## 关联两个数据表

**关联记录**字段会在两个数据表之间建立关系：一对一、一对多、多对一或多对多。关联可以是单向的，也可以是双向的（**在关联表中创建反向关联字段**），并且可以指向另一个数据库。建立关系之后：

- **查找**会取回关联表中的一个字段（把公司名称带到联系人所在的行）；
- **汇总**用 **SUM** 或 **COUNT** 等函数聚合关联记录（某个客户的交易总额，某个项目的任务数）。

**条件查找**和**条件汇总**不需要关联：您选择一个数据表，然后设置条件来筛选其中的记录（状态为“已赢单”的交易总额）。

这些字段会在源数据变化时重新计算。

## 公式

公式在字段级别编写，并应用于所有行。函数分为六类：数值、文本、逻辑、日期和时间、数组、系统。公式可以读取**查找**和**汇总**字段，但不能直接读取另一个数据表中的字段。

```
IF(
  AND({Statut} = "Gagné", {Montant} > 10000),
  "Compte clé",
  "Standard"
)
```

公式不能产生副作用：不能写入其他数据表，也不能发起网络请求。此类需求请使用[自动化](/zh/docs/automations)。

## 默认值与校验

在字段面板中，**默认值**会预先填充新行。它适用于单行文本、长文本、数字、时长、电话、复选框、用户、单选和多选类型。日期类型则改为**自动填充当前日期**。

**字段值校验规则**由两个开关组成：

- **仅允许唯一值**：适用于单行文本、长文本、数字、时长、日期、邮箱、电话和 URL 类型；
- **必填**：适用于上述同类型，以及单选、多选、用户、评分、跟踪时长、附件和关联记录。此规则在修改已有字段时设置，不能在创建字段时设置。

两者都不适用于查找类型的字段。

## 在 Postgres 中的样子

每个数据库是一个 PostgreSQL schema，每张数据表是一张物理表，每个字段是一列。数据库所有者可以在数据库的**设计**页面中打开**只读 Postgres 访问**，然后使用 `psql`、ORM 或 BI 工具读取数据。此访问仅允许读取：所有写入都必须经过 TblFlow。在托管版本中，此功能仅限企业版。见 [API 与开发者](/zh/docs/api-developers)。

## 需要注意的限制

- 重命名字段只会更改其显示名称，不会改变公式中的引用，因为公式依赖的是字段的内部标识符：不会有任何东西被破坏。
- 更改字段类型会转换已有的值。当转换耗时较长或涉及关联字段时，**确认字段变更**窗口会先列出受影响的字段。
- 删除字段会打开一个窗口，列出依赖它的字段。被删除的字段会进入数据表的回收站，在保留期内可以连同其数值一起恢复。见[导入、导出与回收站](/zh/docs/import-export-trash)。
