TblFlow 的官方 MCP 服务器让 Claude 可以在对话中处理您的数据。它是基于 Streamable HTTP 的远程 MCP 服务器，采用 OAuth 2.1 身份验证（即您常用的 TblFlow 登录）。与 REST API 一样，从免费版起即可使用。

服务器 URL：`https://app.tblflow.com/mcp`

## 连接

### Claude（网页版、桌面版和移动端）

1. 打开**设置 → 连接器 → 添加自定义连接器**。
2. 输入 URL `https://app.tblflow.com/mcp`。
3. 使用您的 TblFlow 账户登录。
4. 选择可访问的空间和数据库，再选择权限。

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 23 个工具

服务器提供 23 个工具，分类如下：

- **浏览**：列出您的空间和数据库、数据表的视图以及空间的成员。
- **了解**：描述数据库的结构，读取空间的流程图谱。
- **读取**：列出、筛选和读取记录。
- **计算**：对数据表进行统计（求和、平均值、最小值、最大值、计数），可带筛选和分组，无需读取所有行。
- **搜索**：在 knowledge graph 中进行语义搜索和全文搜索。
- **创建和修改**：创建和修改记录。
- **导入**：导入 CSV，可导入现有数据表，也可导入新数据表。
- **删除和恢复**：删除记录或字段，先预览，再明确确认；列出回收站并恢复已删除的内容。
- **搭建结构**：创建表，创建或重命名字段。
- **自动化**：列出已开放的自动化和智能体，触发自动化。
- **委派**：运行 AI 智能体，并查看其最近几次运行的状态。

## 权限与空间选择

连接时，由您选择可访问的空间和数据库以及权限。**读取**默认开启；**写入**、**删除**、**结构**和**触发**是选项。每次请求都适用您现有的 TblFlow 权限：Claude 能做的事永远不会超过您自己。

## 开放自动化或智能体

只有所有者已**开放**的自动化或智能体，才能从 Claude 触发。目前通过 API 进行开放：`PUT /api/base/:baseId/mcp-exposure`。界面中的开关即将推出。

## 各套餐的限制

| 套餐 | 每分钟请求数 |
| --- | --- |
| 免费版 | 60 |
| Essential | 120 |
| 团队版 | 300 |
| Enterprise | 600 |

## 从终端使用

[TblFlow CLI](/zh/docs/cli) 还提供本地 MCP 服务器（`tblflow mcp serve`），适用于会在您的电脑上启动进程的客户端。它也可用于在命令行中导入 CSV 或导出数据表。

## 撤销访问权限

在 Claude 的设置中删除该连接器：Claude 将不再访问您的 TblFlow 数据。

## 故障排查

- **授权错误**：重新连接该连接器，然后检查该空间或数据库是否为您所选，所需权限（写入、删除、结构或触发）是否已开启，以及您的 TblFlow 权限是否允许该操作。
- **智能体无法启动**：数据库上必须已配置 AI，且该智能体必须已由其所有者开放。
- **`run_automation` 没有改动任何内容**：它是使用示例数据的试运行，不会修改任何数据。

## 数据与隐私

不会记录对话内容：只保留所调用的工具、时间、时长和状态。工具返回的结果会传给助手（Claude），以回应您的请求。详情见[隐私政策](/zh/privacy)和 [MCP 服务器页面](/zh/mcp)。
