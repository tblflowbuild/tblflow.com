视图是读取数据表的一种方式：它不复制任何数据。同一个数据表可以拥有任意多个视图，每个视图都有各自的筛选、排序和可见字段。

## 视图类型

数据表视图标签右侧的 **+** 按钮提供六种类型。新视图以其类型命名（“看板”“日历”等），如果该名称已存在，则在其后加上编号。

| 类型 | 显示内容 | 专属设置 |
|---|---|---|
| **网格视图** | 记录以行显示，字段以列显示。 | 行高、隐藏字段、条件格式。 |
| **画廊视图** | 每条记录显示为一张卡片。 | 封面字段、**自定义卡片**。 |
| **看板视图** | 卡片按列堆叠。 | **选择堆叠字段**、**隐藏空的堆叠**、**自定义卡片**。 |
| **日历视图** | 记录按其日期放置。 | **日历配置**：开始日期、结束日期、标题和颜色字段。 |
| **甘特图视图** | 在时间刻度上显示条形。 | **参数**：开始、结束、标题、依赖和颜色字段。 |
| **表单视图** | 数据表上的录入表单。 | 字段、页面、显示条件、主题颜色。 |

几点说明：

- **日历和甘特图**需要日期字段。甘特图至少需要一个日期或日期/时间字段。条形可以用鼠标拖动，刻度可以在**日**、**周**、**月**或**季度**之间切换。
- **甘特图**：依赖字段通常是**关联到另一条记录**的字段。**周末**和**关键路径**选项在工具栏中设置。循环依赖会被标记，此时关键路径可能不完整。
- **日历和甘特图**显示**待规划**面板，列出没有日期的记录。把其中一条拖到视图上，即可为它设定日期。
- **表单**：您选择显示哪些字段，添加分页，并可以设置某个字段仅在满足条件时才显示。被设为**必填**的字段不能从表单中移除。要发布表单，请参阅[分享与发布](/zh/docs/sharing-publishing)。
- **用 AI 生成**：在同一个 **+** 菜单中，描述您想要的视图，TblFlow 会创建一个视图，包括其类型、筛选、排序和列。

## 管理视图

在视图标签上右键单击，可打开其菜单：

| 操作 | 所需权限 |
|---|---|
| **重命名**、**锁定** / **解锁**、**分享** | 修改视图 |
| **复制** | 创建视图 |
| **删除** | 删除视图 |
| **下载 CSV**（网格视图） | 导出数据表 |
| **添加到收藏** / **从收藏中移除** | 无特殊权限 |

所有者、创建者和编辑者角色可以创建、修改和删除视图。评论者和查看者角色则不行。参见[权限与角色](/zh/docs/permissions)。

**已锁定**的视图会显示一个锁图标。要更改其显示方式，必须切换到个人模式（见下文）。

## 筛选、排序、分组与隐藏

这些设置位于视图的工具栏中。

**筛选。** **添加条件**会增加一行：一个字段、一个运算符和一个值。**添加条件组**可以嵌套条件，最多三层。您可以选择记录需要**满足所有条件**还是**满足任一条件**。

- 运算符取决于字段类型，例如“是”“包含”“为空”“大于”“是其中之一”等。
- 对于用户字段，值**我（当前用户）**会跟随正在查看该视图的人。
- 对于日期，您可以按相对值筛选（今天、昨天、上周、本月、过去或未来的若干天），也可以按确切日期筛选。
- 失效的条件（例如某个列表选项已被删除）会被忽略，并显示警告。

**排序。** **排序**可以接受多个字段；**添加另一个排序**会增加一个。选项**自动排序记录**会让顺序始终保持最新。启用后，手动拖动行的功能将被禁用。

**分组。** **分组**按某个字段对行进行分组，**添加子分组**会增加一级。

**隐藏字段。** 此列表在视图中隐藏字段，但不删除它们。**全部显示**和**全部隐藏**可一次性操作。主字段既不能被隐藏，也不能被删除。

**行高。** 四个级别：短、中、高、很高。

**条件格式。** 规则可以为单个单元格或整行着色（文字或背景）。选项**应用于所有视图**会把该规则扩展到数据表的其他视图。

**快捷开关。** 在网格视图中，**分配给我**和**隐藏已完成**会加入视图的筛选，而无需在其中写入任何内容。只有当数据表有用户字段，或有“已完成”字段（复选框，或某个选项表示已完成的列表）时，这些开关才会出现。

## 协作模式与个人模式

默认情况下，视图是**协作式**的：筛选、排序、分组、隐藏字段和行高都保存在视图中。有人修改时，所有打开该视图的成员都会看到变化。

工具栏中的**个人**按钮会改变这一点：此时的配置只对您生效，并保存在您的浏览器中，而不是服务器上。退出个人模式时，您可以选择放弃这些更改（**确认退出**），或将其应用给所有人（**退出并同步**）。第二个选项需要修改视图的权限。

这也是调整已锁定视图显示方式的唯一途径。

## 记录卡片

每一行都可以打开为一张记录卡片：一个显示该记录全部字段的页面。**位置**菜单可将其放在居中、侧边面板或全屏显示，**上一条记录**和**下一条记录**按钮可在各行之间切换。

卡片的页眉提供**复制记录链接**按钮（用于分享直达链接），以及显示历史记录的按钮。其菜单可以**在数据表中查看**、**打印 / PDF**、**复制记录**和**删除记录**。

视图中隐藏的字段仍可通过**显示 N 个隐藏字段**访问。

**布局。** **布局**菜单用于设置字段顺序、宽度（半宽或全宽）以及可折叠的分区。您可以创建多个命名布局。更改对视图的所有用户生效。

**历史记录。** 历史记录列出每次修改，包括**修改前**和**修改后**的值。可以按时间范围、字段和用户筛选，并以表格（**以表格查看**）或句子（**以句子查看**）形式显示。数据表菜单中还提供**数据表的记录历史**，仅限所有者、创建者和编辑者角色使用。

## 评论

卡片上的**评论**标签会打开该记录的讨论。评论可以包含链接、图片、提及、表情符号、语音消息或屏幕剪辑。您可以选择接收**所有评论**的通知，或仅接收与您相关的评论。**活动**标签显示该记录的历史；只有能够修改记录的角色才能看到它。

发表评论需要评论权限：所有者、创建者、编辑者和评论者角色拥有该权限，查看者角色没有。

**语音消息和屏幕剪辑。** 评论编辑器的工具栏提供**录制语音消息**和**录制屏幕剪辑**。浏览器会请求麦克风或屏幕的访问权限；若被拒绝，则显示“麦克风或屏幕访问被拒绝。”。录制期间可以看到已用时间，**停止**会结束录制；录制内容随后发送，并附加到评论中。语音消息最长 5 分钟，屏幕剪辑最长 3 分钟；超过时长后，录制会自动停止。

**向 AI 助手提问。** 在评论中输入 **@**，然后选择 **IA**（在提及列表中显示为 **Assistant IA**）：数据库的助手会读取该行，然后以署名“Assistant IA”的评论作答。它会在首次调用时在数据库中创建。它可以搜索和读取记录、数据表、其结构以及某一行的活动，并查阅知识库。它也可以创建或修改记录，但每次写入都需要人工确认（参见[AI 智能体](/zh/docs/ai-agents)中的**写入校验**）。其回复限制为 4000 个字符。AI 配额和适用的权限是提及者本人的；如果 AI 被拒绝（配额已用完、拒绝数据处理），回复评论会注明原因。如果数据库中的“Assistant IA”智能体已停用，@IA 将不再回复。

## 仪表板

数据库侧边栏中的**仪表板**入口会打开一个页面，汇集图表和指标。该页面列出**您的仪表板**，即数据库中各数据表的图表类视图。要创建仪表板，**用 AI 创建**会启动聊天，您可以自由描述需求；**模板**部分提供三个起点：**项目跟踪**、**CRM** 和**流程图谱成本**。该入口需要具备读取数据库的权限才可见。

## 白板

白板是数据库中与数据表并列的一种资源：一块自由的空间，用于在结构化之前先进行思考。从侧边栏的 **+** 菜单中创建，位于**其他资源**分类下的**新建白板**。创建白板需要修改数据库的权限：所有者和创建者角色拥有该权限。

- 工具：**选择**、**便利贴**、**文本**、**框架**、**记录**、**画笔**、**图片**、**评论**。**记录**工具会在白板上放置一张与现有记录关联的卡片。
- 六个起始模板：头脑风暴、项目规划、流程、数据库设计、复盘、组织结构图。您也可以从空白画布开始。
- **利用此白板**会把所选内容转化为数据表中的记录。对于框架，它还会建议数据表，您需在创建前确认。
- **导出**可生成 PNG 图片或 PDF 文档。

## 图表

图表放在**插件面板**中，位于数据表旁边，无需创建视图。面板按钮（拼图图标）位于数据表工具栏中。

1. 打开面板。若面板为空，点击**创建插件面板**，输入名称，然后用**确认**保存。
2. 在面板中点击**添加插件**，然后点击**图表**旁边的**安装**。
3. 第一个界面**数据查询配置**要求您构建为图表提供数据的查询，可使用以下模块：**从**、**选择**、**条件**、**分组依据**、**聚合**、**排序依据**、**限制**、**偏移**和**连接**。点击**保存**。
4. 然后在右侧面板中选择**图表类型**：**柱状图**、**折线图**、**饼图**、**面积图**或**表格**。

设置项取决于图表类型：

- **柱状图、折线图、面积图**：**X 轴**、**Y 轴**、**添加另一个系列**、**添加系列拆分**、**堆叠**、**目标线**、**范围**（**最小值**、**最大值**）、**线条样式**、**Y 轴位置**；
- **饼图**：**维度**、**度量**、**显示总计**；
- 对于支持它们的类型，可使用**在图表上显示数值标签**和**显示图例**。

每个图表的标题栏提供**展开**、**复制**、**重命名**和**删除**。**重命名**和**删除**需要修改数据表的权限。**更新查询**按钮会重新打开查询配置，**重新加载查询**则会重新读取数据。
