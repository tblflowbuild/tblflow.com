本页带您从一个空账户走到一个与团队共享的数据库。预计用时五分钟。

## 1. 创建数据库

在空间中点击**新建数据库**。数据库汇集了数据表、自动化和智能体；每个数据表都有自己的视图。在底层，每个数据库都是一个专用的 PostgreSQL schema。

窗口会询问您想构建什么：

- **描述应用**：输入您要跟踪的内容（“一个为培训中心管理课程排期的工具”），然后点击**生成应用**。AI 会提出数据结构、视图、界面和自动化方案，您可以逐步确认。如果空间尚未配置 AI，按钮会变为**接入 AI 以生成**，并引导您进入设置。见 [AI 聊天](/zh/docs/ai-chat)。
- **从空白数据库开始**：数据库创建时不经过 AI 生成；之后再逐个添加数据表。

在尚未包含任何数据库的空间中，您还可以**从模板开始**。模板**项目管理**属于 TblFlow 自带的模板库：它会创建项目、任务（含子任务和依赖关系）、迭代（Sprint）和人员数据表，以及看板、甘特图和日历视图，还有一个按状态分组并带合计的**仪表板**视图，以及两个自动化，用于填写或清空任务的“完成日期”。模板附带一个项目、一个迭代和五个示例任务，可以按需修改或删除。从另一个数据库导出的 **.tbl** 文件，可以通过**导入**重新导入到空间中。见 [导入、导出与回收站](/zh/docs/import-export-trash)。

### 添加数据表

在数据库的侧边栏中，添加按钮提供以下选项：

- **新建数据表**：手动定义字段；
- **用 AI 创建**：描述数据表，预览结果会显示出来，在您点击**创建**之前不会创建任何内容；
- **从其他来源添加**：导入 CSV、TSV 或 Excel 文件，或导入文件链接（**链接（URL）**）。字段类型会根据数据推断（选项**自动选择字段类型**），您可以在导入前修改。从电子表格复制的单元格也可以粘贴到表格视图中。

## 2. 规划字段

字段类型是数据库与电子表格的区别所在。请花点时间正确设置它，因为其他部分（公式、筛选、自动化）都依赖于它。

| 您的需求 | 使用的类型 |
| --- | --- |
| 固定集合中的一个值 | 单选 |
| 指向另一个数据表的链接 | 关联记录 |
| 来自关联数据表的值 | 查找 |
| 对关联记录的汇总 | 汇总 |
| 逐行计算 | 公式 |

字段类型不受您的套餐限制。见 [数据表与字段](/zh/docs/tables-and-fields)。

## 3. 打开第二个视图

视图是对数据表的一种读取方式，而不是副本。切换视图不会复制任何数据。

对于带有状态字段的数据表，可以添加按该状态分栏的**看板**视图。对于带有日期的数据表，可以添加**日历**或**甘特图**视图。筛选、排序和分组都保存在各自的视图中。默认情况下，视图是协作式的：如果同事修改了“我的逾期事项”的筛选条件，所有人都会看到这一变化。**个人**按钮可将您的设置仅限于您自己。见 [视图与筛选](/zh/docs/views-and-filters)。

## 4. 邀请团队

数据库侧边栏中的**邀请**按钮会打开共享设置；只有可以编辑数据库的角色才能使用它。每个人都会被分配一个角色：创建者、编辑者、评论者或查看者（数据库级别）。所有者角色则在空间级别设置。也可以在数据库或数据表上设置自定义角色。如需对外发布或分享视图，见 [分享与发布](/zh/docs/sharing-publishing)。另见 [权限与角色](/zh/docs/permissions)。

编辑支持实时协作：两个人可以同时修改同一个数据表，每位参与者的当前单元格都会在表格中标示出来。
