本页带您从一个空账户走到团队可以协作的数据库。预计用时五分钟。

## 1. 创建数据库

在控制台中点击**新建数据库**。数据库是一个工作空间：它包含多个数据表、自己的视图、自动化和智能体。其底层是一个专用的 PostgreSQL schema。

有三种开始方式：

- **空白表**：自己定义字段。
- **导入**：CSV、Excel，或直接从电子表格粘贴。字段类型会根据数据推断，您可以在确认之前进行修正。
- **用自然语言描述**：描述您要跟踪的内容（“包含联系人、公司和交易的销售管道”），助手会提出一套 schema 方案。在您接受方案之前，不会创建任何内容。

## 2. 选对字段类型

字段类型是数据库与电子表格的区别所在。请花一分钟来确定它，因为公式、筛选和自动化都依赖于它。

| 您需要什么 | 字段类型 |
| --- | --- |
| 固定选项中的一个值 | 单选 |
| 指向另一个数据表的链接 | 关联记录 |
| 从关联数据表中取出的值 | 查找 |
| 对关联记录的汇总 | 汇总 |
| 逐行计算 | 公式 |

全部 28 种类型在每个套餐中都可用，包括自托管。

## 3. 打开第二个视图

视图是对数据表的一种读取方式，而不是副本。切换视图不会复制任何内容。

对于带有状态字段的数据表，可以添加按该状态分组的**看板**视图。对于带有日期的数据表，可以添加**日历**或**甘特图**视图。筛选、排序和分组都属于视图：同事的“我的逾期事项”视图不会改变您的视图。

## 4. 邀请团队

点击右上角的**分享**。权限在数据库层面设置（所有者、编辑者、评论者、查看者），并可以进一步收窄到每个数据表和每个字段。

编辑支持实时协作：两个人可以同时在同一个数据表中工作，光标和更改立即可见。
