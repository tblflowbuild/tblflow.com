Офіційний MCP-сервер TblFlow дозволяє Claude працювати з вашими даними прямо з розмови. Це віддалений MCP-сервер у форматі Streamable HTTP з автентифікацією OAuth 2.1 (ваш звичний вхід у TblFlow). Він доступний уже з тарифу «Безкоштовний», як і [REST API](/uk/docs/api-developers).

URL сервера: `https://app.tblflow.com/mcp`

## Підключення

### Claude (веб, десктоп і мобільний застосунок)

1. Відкрийте **Налаштування → Конектори → Додати власний конектор**.
2. Введіть URL `https://app.tblflow.com/mcp`.
3. Увійдіть зі своїм обліковим записом TblFlow.
4. Виберіть простори й бази, до яких матиме доступ Claude, а потім дозволи.

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 27 інструментів

Сервер надає 27 інструментів, які згруповані так:

- **Переглядати**: показати ваші простори (`list_workspaces`), подання таблиці (`list_views`) і учасників простору (`list_collaborators`, без їхніх адрес електронної пошти).
- **Розуміти**: описати схему бази (`describe_base`), прочитати карту процесів простору (`get_process_map`).
- **Читати**: показати, відфільтрувати та прочитати записи, до 100 за один виклик (`list_records`, `get_record`).
- **Обчислювати**: порахувати статистику по таблиці (`aggregate_records`) з фільтром і групуванням, не читаючи всі рядки. Функції: кількість, порожні, заповнені, унікальні значення, мінімум, максимум, сума, середнє, відсотки порожніх, заповнених і унікальних значень, найраніша та найпізніша дата.
- **Шукати**: шукати в графі знань семантичним і повнотекстовим пошуком (`search_knowledge`).
- **Створювати й змінювати**: створювати й змінювати записи, до 50 за один виклик (`create_records`, `update_records`).
- **Імпортувати**: імпортувати CSV до 2 МіБ у наявну таблицю або в нову (`import_csv`). За замовчуванням перший виклик лише показує колонки, визначені типи та кількість рядків, нічого не записуючи.
- **Видаляти й відновлювати**: видаляти записи або поле (`delete_records`, `delete_field`) з попереднім переглядом і явним підтвердженням; показати кошик таблиці та відновити видалене (`list_trash`, `restore_records`).
- **Структурувати**: створити таблицю (`create_table`), створити поле (`create_field`), змінити назву, опис і для поля Canvas — його параметри (`update_field`). Тип поля ніколи не змінюється.
- **Документи та картки Canvas**: прочитати картку рядка (`get_canvas_doc`), змінити її (`update_canvas_doc`), запустити генерацію карток поля Canvas для 25 рядків за один виклик (`generate_canvas_docs`, що витрачає ШІ-кредити в режимі ШІ), а також прочитати документ простору (`get_doc`).
- **Автоматизувати**: показати відкриті автоматизації й агентів (`list_exposed_actions`), пробно запустити автоматизацію (`run_automation`).
- **Делегувати**: запустити агента ШІ (`run_agent`, очікування не більше ніж близько 100 секунд) і стежити за станом його останніх запусків (`get_run_status`).

Кожен інструмент викликає REST API з вашим токеном: сервер не відкриває жодного додаткового доступу.

## Ресурси та промпти

Сервер також публікує три ресурси для читання та три готові промпти.

| Тип | Назва | Зміст |
|---|---|---|
| Ресурс | `tblflow://workspaces` | Доступні простори (не більше 30) |
| Ресурс | `tblflow://bases/{baseId}` | Таблиці бази |
| Ресурс | `tblflow://tables/{tableId}` | Поля таблиці |
| Промпт | `summarize_table` | Описати таблицю й виділити ключові цифри, не змінюючи її |
| Промпт | `audit_data_quality` | Знайти порожні поля й імовірні дублікати, нічого не виправляючи |
| Промпт | `add_rows_safely` | Додати записи після перевірки схеми й лише після вашої згоди |

## Дозволи та вибір просторів

Під час підключення TblFlow показує екран «запитує доступ до вашого облікового запису». На ньому перелічено запитувані дозволи з такими назвами:

| Дозвіл | Назва на екрані |
| --- | --- |
| Читання (за замовчуванням) | Читати ваші дані (простори, таблиці, записи, документи) |
| Запис | Створювати та змінювати записи |
| Видалення | Видаляти записи (кошик) |
| Схема | Створювати таблиці та поля |
| Запуск | Пробно запускати автоматизації та запускати відкриті вами агенти |

Далі потрібно вибрати простори й бази, доступні застосунку. Позначений простір охоплює всі його бази. Якщо TblFlow не перевірив застосунок, на екрані з’явиться напис «Застосунок не перевірено»: надавайте доступ, лише якщо ви самі ініціювали підключення, і перевірте показаний хост перенаправлення.

**Читання** увімкнене за замовчуванням; **запис**, **видалення**, **схема** і **запуск** є опціями. Видалення включає відновлення з кошика. Імпорт CSV у наявну таблицю потребує запису; імпорт, що створює таблицю, потребує схеми. Ваші наявні права в TblFlow діють для кожного запиту: Claude ніколи не зможе зробити більше, ніж можете ви.

## Відкрити доступ до автоматизації або агента

Автоматизацію чи агента можна запустити з Claude, лише якщо його власник **відкрив до нього доступ**. Наразі це робиться через API: `PUT /api/base/:baseId/mcp-exposure`. Перемикач в інтерфейсі з’явиться пізніше.

## З термінала

[CLI TblFlow](/uk/docs/cli) також надає локальний MCP-сервер (`tblflow mcp serve`) для клієнтів, які запускають процес на вашому комп’ютері. Він також використовується для імпорту CSV та експорту таблиць із командного рядка.

## Відкликання доступу

Видаліть конектор у налаштуваннях Claude: Claude припинить доступ до ваших даних TblFlow.

## Усунення проблем

- **Помилка авторизації**: підключіть конектор повторно, потім перевірте, що простір або база входить до обраних вами, що потрібний дозвіл (запис, видалення, схема або запуск) увімкнено і що ваші права в TblFlow це дозволяють.
- **Агент не запускається**: у базі має бути налаштовано ШІ, а власник агента має відкрити до нього доступ.
- **`run_automation` нічого не змінює**: це пробний запуск на зразкових даних. Жодні дані не змінюються.

## Дані та конфіденційність

Зміст розмов не журналюється: зберігаються лише викликаний інструмент, час, тривалість і стан. Результати інструментів передаються асистенту (Claude), щоб відповісти на ваш запит. Докладніше — у [політиці конфіденційності](/uk/privacy) та на [сторінці MCP-сервера](/uk/mcp).
