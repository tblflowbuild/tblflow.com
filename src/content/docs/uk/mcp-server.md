Офіційний MCP-сервер TblFlow дозволяє Claude працювати з вашими даними просто з розмови. Це віддалений MCP-сервер через Streamable HTTP з автентифікацією OAuth 2.1 (ваш звичний вхід у TblFlow). Він доступний уже в тарифі «Безкоштовний», як і REST API.

URL сервера: `https://app.tblflow.com/mcp`

## Підключення

### Claude (веб, десктоп і мобільний застосунок)

1. Відкрийте **Налаштування → Конектори → Додати власний конектор**.
2. Введіть URL `https://app.tblflow.com/mcp`.
3. Увійдіть зі своїм обліковим записом TblFlow.
4. Виберіть простори й бази, до яких надається доступ, а потім дозволи.

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 13 інструментів

Сервер надає 13 інструментів, згрупованих так:

- **Переглядати**: показати перелік ваших просторів і баз.
- **Розуміти**: описати схему бази.
- **Читати**: показати, відфільтрувати й прочитати записи.
- **Шукати**: шукати в knowledge graph — семантичним і повнотекстовим пошуком.
- **Створювати й змінювати**: створювати й змінювати записи.
- **Видаляти**: видаляти записи — з попереднім переглядом, а потім із явним підтвердженням. Записи потрапляють до кошика.
- **Структурувати**: створити таблицю або поле.
- **Автоматизувати**: запустити автоматизацію.
- **Делегувати**: запустити агента ШІ.

## Дозволи та вибір просторів

Під час підключення ви вибираєте простори й бази, до яких надається доступ, та дозволи. **Читання** ввімкнене за замовчуванням; **запис**, **видалення**, **схема** і **запуск** є опціями. Ваші наявні права в TblFlow діють для кожного запиту: Claude ніколи не зможе зробити більше, ніж можете ви.

## Відкрийте доступ до автоматизації або агента

Автоматизацію чи агента можна запустити з Claude, лише якщо його власник **відкрив до нього доступ**. Наразі це робиться через API: `PUT /api/base/:baseId/mcp-exposure`. Перемикач в інтерфейсі з’явиться згодом.

## Відкликання доступу

Видаліть конектор у налаштуваннях Claude: Claude припинить доступ до ваших даних TblFlow.

## Усунення проблем

- **Помилка авторизації**: підключіть конектор повторно, потім перевірте, що простір або база входять до обраних вами, що потрібний дозвіл (запис, видалення, схема або запуск) увімкнено і що ваші права в TblFlow це дозволяють.
- **Агент не запускається**: у базі має бути налаштовано ШІ, а власник агента має відкрити до нього доступ.
- **`run_automation` нічого не змінює**: це пробний запуск на прикладних даних. Жодні дані не змінюються.

## Дані та конфіденційність

Зміст розмов не журналюється: зберігаються лише викликаний інструмент, час, тривалість і стан. Результати інструментів передаються асистенту (Claude), щоб відповісти на ваш запит. Докладніше — у [політиці конфіденційності](/uk/privacy) та на [сторінці MCP-сервера](/uk/mcp).
