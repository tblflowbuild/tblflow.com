CLI TblFlow керує вашими базами з термінала: читає й записує записи, імпортує та експортує CSV, запускає відкриті для доступу автоматизації й агентів та підключає локальний MCP-клієнт (Claude Code, Cursor…) до ваших даних. Його опубліковано в npm під назвою `@tblflow/cli` за ліцензією MIT.

Потрібен Node.js 20 або новіший; сторонніх залежностей немає.

## Встановлення

```bash
npm install -g @tblflow/cli
tblflow --help
```

Без встановлення: `npx @tblflow/cli --help`.

## Вхід

### На вашому комп’ютері

```bash
tblflow login     # відображається код, ви підтверджуєте його в браузері
tblflow whoami
tblflow logout    # видаляє локальну сесію й відкликає токен на сервері
```

Перш ніж підтверджувати, переконайтеся, що код у терміналі збігається з кодом у браузері. Токени зберігаються у зв’язці ключів системи (macOS, Linux Secret Service). Якщо її немає, вони зберігаються в `~/.config/tblflow/credentials.json`, доступному лише вам, і CLI вас про це попередить.

### У безперервній інтеграції

Створіть **службовий токен** у TblFlow: налаштування простору → Безпека й аудит → Службові облікові записи. Збережіть його в секретах вашого CI, а потім передайте як змінну середовища:

```bash
export TBLFLOW_TOKEN=...      # підставляється CI, ніколи не записується в репозиторій
tblflow bases
```

`TBLFLOW_TOKEN` має пріоритет над будь-якою збереженою сесією й ніколи не записується на диск. Щоб один раз зберегти токен на виділеному комп’ютері, прочитайте його зі стандартного вводу:

```bash
printenv TBLFLOW_TOKEN | tblflow login --token -
```

`tblflow login --token <токен>` теж працює, але тоді токен лишається в історії оболонки та в списку процесів: CLI про це нагадує. Токен перевіряється на сервері перед збереженням і не з’являється в жодному виводі чи повідомленні про помилку. `tblflow logout` забуває токен, збережений таким чином, але не відкликає його: відкликання виконується в налаштуваннях простору.

### Вибір сервера

За замовчуванням CLI звертається до `https://app.tblflow.com`. Для іншого сервера використовуйте `--host https://…` або змінну `TBLFLOW_URL`. HTTPS обов’язковий, за винятком `localhost`.

## Команди

| Команда | Дія |
|---|---|
| `bases` | Доступні простори й бази |
| `tables <baseId>` | Таблиці бази |
| `records list <tableId>` | `--take N` (щонайбільше 100), `--skip N`, `--fields a,b`, `--where "Поле=v"`, `--sort "Поле:desc"` |
| `records get <tableId> <recordId>` | Читає запис |
| `records create <tableId>` | `--data '<json>'` або `--file f.json` (щонайбільше 50) |
| `records update <tableId> [<recordId>]` | Оновлює один або кілька записів |
| `records delete <tableId> <recordId>…` | Попередній перегляд, потім видалення (кошик) із `--confirm` |
| `import <tableId> <файл.csv>` | Додає рядки з CSV; `--dry-run` |
| `import --new-table <baseId> <файл.csv>` | Створює таблицю з CSV; `--name`, `--dry-run` |
| `export <tableId>` | CSV у стандартний вивід або `--out файл.csv`; `--view <viewId>` |
| `run automation <baseId> <workflowId>` | Запускає автоматизацію, відкриту для доступу її власником |
| `run agent <baseId> <agentId> <завдання…>` | Запускає агента, відкритого для доступу його власником |
| `api <МЕТОД> <шлях>` | Прямий виклик, лише шляхи `/api/`; `DELETE` вимагає `--confirm` |
| `mcp serve` | Локальний MCP-сервер (stdio) |

`--json` працює з усіма командами. Коди завершення: 0 у разі успіху, 1 у разі помилки, 2 для помилки використання або коли потрібне підтвердження.

### Створення таблиці з CSV

```bash
tblflow import --new-table <baseId> clients.csv --name "Clients" --dry-run
tblflow import --new-table <baseId> clients.csv --name "Clients"
```

`--dry-run` показує, що було б створено, нічого не записуючи.

## Підключення локального MCP-клієнта

`tblflow mcp serve` запускає локальний MCP-сервер на стандартному вводі й виводі. Оголосіть його в конфігурації вашого MCP-клієнта:

```json
{ "mcpServers": { "tblflow": { "command": "npx", "args": ["-y", "@tblflow/cli", "mcp", "serve"] } } }
```

Щоб підключити Claude (веб, десктоп чи мобільний) без жодного встановлення, скористайтеся віддаленим MCP-сервером: див. посібник [MCP-сервер](/uk/docs/mcp-server).
