TblFlow предлагает пять способов открыть доступ к вашим данным. Они требуют разных прав и дают разные возможности, поэтому выбирайте самый узкий способ, которого достаточно.

| Что вы хотите | Где | Требуемое право (роли по умолчанию) |
|---|---|---|
| Показать представление только для чтения, по ссылке | Панель инструментов таблицы, **Поделиться** | Изменение представления и его общий доступ: владелец, создатель, редактор |
| Показать таблицу или базу, по ссылке | **Поделиться** (панель инструментов или меню базы) | Изменение базы: владелец, создатель |
| Получать ответы | Представление «Форма» с общим доступом | То же, что для представления |
| Опубликовать приложение | Кнопка **Опубликовать** в приложении | Изменение приложения: владелец, создатель |
| Привлечь кого-то к работе в пространстве или базе | Кнопка **Пригласить** | Приглашение: см. [Права доступа и роли](/ru/docs/permissions) |

## Поделиться представлением по ссылке

В панели инструментов таблицы кнопка **Поделиться** открывает небольшое меню: **Поделиться таблицей** и **Поделиться представлением**. Кнопка неактивна без права изменять представление.

Выберите **Поделиться представлением**, затем включите **Поделиться представлением в интернете**. Появится ссылка с кнопкой копирования в один клик, QR-код и кнопка для создания новой ссылки. Те, у кого есть ссылка, видят представление без учётной записи.

В разделе **Дополнительно**, в зависимости от типа представления:

- **Разрешить зрителям копировать данные из этого представления** и **Показывать все поля в развёрнутых записях** (только для представления «Сетка»).
- **Только по приглашению**: см. ниже.
- **Настройка встраивания**: копирует код `iframe` для вставки на другую страницу, с предпросмотром. Там вы выбираете тему (системная, светлая или тёмная) и, кроме формы, **Скрыть панель инструментов**. Эти настройки меняют ссылку: скопируйте её заново после изменения.

Поля типа **Пароль** никогда не отправляются человеку, который открывает ссылку общего доступа. Поле, которое база запрещает читать, тоже не отправляется.

Выключите переключатель, чтобы закрыть ссылку. Создание новой ссылки меняет адрес.

## Поделиться таблицей или базой по ссылке

Для всей базы используйте **Поделиться** в меню базы (список баз пространства). Для таблицы нажмите **Поделиться**, затем **Поделиться таблицей**. Нужно право изменять базу: по умолчанию его имеют владелец и создатель.

Включите **Поделиться в интернете**. Ссылка открывается по адресу `/share/…/base`. Меню **Любой, у кого есть ссылка** задаёт, что именно позволяет ссылка:

| Настройка | Эффект |
|---|---|
| **Может просматривать** | Любой, у кого есть ссылка, видит данные. |
| **Может изменять** | Вошедшие пользователи изменяют записи таблицы: они получают права редактора. Доступно для базы, таблицы или папки. |
| **Сохранить копию** | Любой, у кого есть ссылка, может сохранить копию в своё пространство. |

В разделе **Дополнительно**: **Разрешить читателям копировать данные**, **Только по приглашению** и **Настройка встраивания** (код `iframe`). **Пересоздать ссылку** меняет адрес. Отключение **Поделиться в интернете** требует подтверждения: действие необратимо, а те, у кого была ссылка, теряют доступ.

Даже с настройкой **Может изменять** ссылка на базу не даёт приглашения по e-mail, общего доступа к представлению и запросов к данным.

## Ограничить ссылку приглашёнными

**Только по приглашению** применяется к ссылкам представлений и баз. Появляется поле **Приглашённые**: введите адреса через запятую, точку с запятой или пробел, затем нажмите **Пригласить**.

- Ссылка должна быть включена до приглашения. За одну отправку можно указать до 50 адресов.
- Письмо со ссылкой получают только новые адреса.
- Человек должен войти в TblFlow. Если его учётная запись не приглашена, он видит сообщение «Доступ по приглашению» и может сменить учётную запись.
- Участники базы получают доступ без приглашения.
- Добавлять и удалять приглашённых может только тот, у кого есть право изменять пространство, то есть владелец по умолчанию.

## Публичная форма

Представление «Форма» делится так же, как любое другое: **Поделиться** > **Поделиться представлением** > **Поделиться представлением в интернете**. Любой, кто открывает ссылку, может заполнить форму и отправить её; ответы появляются как записи таблицы.

Опция **Требовать вход для отправки** обязывает человека войти в TblFlow перед отправкой. В этом случае форму закрывают сообщение и кнопка **Войти**. При **Только по приглашению** доступ к форме имеют только приглашённые и участники базы.

## Опубликовать приложение

В редакторе приложения кнопка **Опубликовать** открывает панель **Публикация приложения**. Там настраивается следующее:

| Настройка | Значения |
|---|---|
| **Доступ** | **Публичный — любой, у кого есть ссылка**, или **По приглашению — приглашённые и участники базы** |
| **Разрешить запись данных** | По умолчанию выключено: посетители только читают данные |

По умолчанию предлагается доступ **По приглашению**. Выбор **Публичный** требует подтверждения: без учётной записи и приглашения любой, кто получит ссылку, откроет приложение и увидит данные, которые в нём отображаются.

Нажмите **Опубликовать — сгенерировать ссылку**. Панель покажет ссылку, которую можно скопировать. Затем вы можете менять доступ и запись без повторной публикации.

В режиме **По приглашению** каждый входит под своей учётной записью TblFlow, без пароля: по волшебной ссылке или с помощью ключа безопасности. Войти может тот, кого пригласили или кто является участником базы; в остальных случаях страница сообщит об отказе. Поле **Приглашённые** работает так же, как для ссылок на представления, но приложение должно быть опубликовано до приглашения. У приложения нет пароля общего доступа и собственной учётной записи для посетителей.

Раздел **Персонализация** позволяет загрузить значок вкладки (favicon) и написать **Описание страницы**, которое показывают поисковые системы и превью ссылок.

**Снять с публикации (отозвать ссылку)** отключает ссылку после подтверждения. Повторная публикация создаёт новую ссылку. Публикация, снятие с публикации и изменение доступа требуют права изменять приложение; управление приглашёнными требует права изменять пространство.

Что касается построения самого приложения, см. [Создайте первое приложение](/ru/docs/build-first-app).

## Пользовательский домен

Опубликованное приложение может открываться в корне доменного имени, которое вам принадлежит. Сначала этот домен нужно подтвердить в настройках пространства.

1. В настройках пространства, на вкладке **Проверенные домены**, нажмите **Добавить домен** и введите имя (например, `app.mydomain.com`).
2. У своего DNS-провайдера добавьте показанную TXT-запись: её имя начинается с `_tblflow-verify.`, а значение — с `tblflow-verify=`.
3. Нажмите **Проверить**. Домен перейдёт в статус **Проверен**.
4. В панели публикации приложения, в разделе **Пользовательский домен**, выберите домен в поле **Выбрать проверенный домен…**. Кнопка **Отвязать** его удаляет.

Один домен обслуживает одно приложение и может быть проверен только в одном пространстве. Если проверенных доменов нет, панель сообщает: «Нет доступных проверенных доменов». TXT-запись доказывает, что домен принадлежит вам; это единственное, что проверяет TblFlow. Через семь дней это доказательство перепроверяется, когда домен обслуживает приложение: если запись исчезла, домен снова становится непроверенным.

## Пригласить соавторов

Приглашение соавтора даёт ему роль в пространстве или базе; это не общий доступ по ссылке. Права каждой роли описаны в [Права доступа и роли](/ru/docs/permissions).

- **Пространство**: кнопка **Пригласить** в пространстве, окно «Поделиться пространством». Соавтор пространства получает доступ ко всем его базам.
- **База**: кнопка приглашения (значок пользователя, всплывающая подсказка **Пригласить**) на панели базы, окно «Поделиться» с названием базы.

Каждое окно предлагает:

- **Пригласить по e-mail**: введите адреса (подтверждайте каждый клавишей Enter или пробелом), выберите роль и нажмите **Отправить приглашение**.
- **Пригласить по ссылке**: выберите роль и нажмите **Создать ссылку**. Любой, кто откроет ссылку, получит эту роль после входа. Роль ссылки можно изменить, а **Удалить ссылку** её отзывает. Доступно только владельцу и создателю по умолчанию.
- Добавление участника или отдела организации, если ваша учётная запись относится к организации.
- Список соавторов с поиском по имени или e-mail, сменой роли и кнопкой **Удалить соавтора**.
