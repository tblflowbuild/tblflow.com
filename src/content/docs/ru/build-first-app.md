База TblFlow доступна не только для просмотра в таблице: её можно опубликовать как настоящее приложение со своими страницами, ссылкой для всех или только для приглашённых и собственным доменом. На этой странице описаны два способа его создать.

## Вариант 1 — опишите его ИИ

В панели чата базы выберите режим **Полное приложение**, затем опишите, что вам нужно: «CRM с панелью управления, списком контрагентов и воронкой сделок в виде канбан-доски». Генерация идёт по этапам: сначала таблицы и их связи, затем интерфейс, автоматизации, представления и тестовые данные, и наконец ИИ-агент. Каждый этап создаёт предложения, которые вы принимаете, прежде чем перейти к следующему, и пока ни одно предложение не принято, вы можете его изменить. Ничего не публикуется, пока вы не нажмёте **Опубликовать**.

## Вариант 2 — соберите в редакторе

В базе в меню создания есть пункт **Новое приложение** (если чат ИИ включён и вам разрешено создавать приложения). Редактор открывается с тремя вкладками, **Предпросмотр**, **Код** и **Журнал**, и чатом ИИ справа: опишите в нём приложение, затем уточняйте детали.

Нажатие на блок в предпросмотре ссылает на него в чате. **Редактировать текст напрямую** исправляет отображаемый текст, не отправляя отдельный запрос. **История** показывает версии приложения; **Восстановить эту версию** возвращает то состояние, которое вы выбрали.

## Публикация

Кнопка **Опубликовать** в верхней части редактора открывает панель **Публикация приложения**. Доступны два режима доступа на выбор:

- **По приглашению — приглашённые люди и участники базы** (предлагается по умолчанию). Каждый входит под своей учётной записью TblFlow без пароля: по волшебной ссылке или с помощью ключа безопасности.
- **Публичный — любой, у кого есть ссылка.** Потребуется подтверждение: тот, кто получит ссылку, откроет приложение без учётной записи и увидит данные, которые в нём отображаются.

**Разрешить запись данных** по умолчанию отключено. Приложение только для чтения ничего не может сломать; включайте запись, только если посетителям действительно нужно создавать или изменять записи из приложения.

Нажатие **Опубликовать — создать ссылку** сразу формирует URL. Ни пароля для общего доступа, ни отдельной учётной записи посетителя для приложения не предусмотрено. Приглашённые, настройка страницы, отмена публикации и собственный домен описаны в разделе [Общий доступ и публикация](/ru/docs/sharing-publishing).

## Код остаётся у вас

Опубликованное приложение — это настоящий код React и Tailwind, а не чёрный ящик: **Код → Экспортировать код** позволяет получить его целиком. И наоборот, **Импортировать код** позволяет начать с существующей базы и вручную адаптировать её после генерации ИИ.
