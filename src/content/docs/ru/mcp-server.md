Официальный MCP-сервер TblFlow позволяет Claude работать с вашими данными прямо из разговора. Это удалённый MCP-сервер в режиме Streamable HTTP с аутентификацией OAuth 2.1 (ваш обычный вход в TblFlow). Он доступен уже на тарифе Бесплатный, как и [REST API](/ru/docs/api-developers).

URL сервера: `https://app.tblflow.com/mcp`

## Подключение

### Claude (веб, компьютер и мобильное приложение)

1. Откройте **Настройки → Коннекторы → Добавить пользовательский коннектор**.
2. Введите URL `https://app.tblflow.com/mcp`.
3. Войдите под своей учётной записью TblFlow.
4. Выберите доступные пространства и базы, затем разрешения.

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 27 инструментов

Сервер предоставляет 27 инструментов, которые делятся на такие группы:

- **Изучать**: показать ваши пространства и базы (`list_workspaces`), представления таблицы (`list_views`) и участников пространства (`list_collaborators`, без их адресов электронной почты).
- **Понимать**: описать схему базы (`describe_base`), прочитать карту процессов пространства (`get_process_map`).
- **Читать**: показать, отфильтровать и прочитать записи, не более 100 за вызов (`list_records`, `get_record`).
- **Считать**: вычислить статистику по таблице (`aggregate_records`) с фильтром и группировкой, без чтения всех строк. Функции: количество, пустые, заполненные, уникальные значения, минимум, максимум, сумма, среднее, доли пустых, заполненных и уникальных значений, самая ранняя и самая поздняя дата.
- **Искать**: поиск в графе знаний, семантический и полнотекстовый (`search_knowledge`).
- **Создавать и изменять**: создавать и изменять записи, не более 50 за вызов (`create_records`, `update_records`).
- **Импортировать**: импортировать CSV размером не более 2 Мио в существующую таблицу или в новую (`import_csv`). По умолчанию первый вызов показывает только столбцы, угаданные типы и число строк, ничего не записывая.
- **Удалять и восстанавливать**: удалять записи или поле (`delete_records`, `delete_field`) с предварительным просмотром и затем явным подтверждением; показать корзину таблицы и восстановить удалённое (`list_trash`, `restore_records`).
- **Структурировать**: создать таблицу (`create_table`), создать поле (`create_field`), изменить название, описание и, для поля Canvas, параметры поля (`update_field`). Тип поля никогда не меняется.
- **Документы и карточки Canvas**: прочитать карточку строки (`get_canvas_doc`), изменить её (`update_canvas_doc`), запустить генерацию карточек поля Canvas не более чем для 25 строк за вызов (`generate_canvas_docs`, в режиме ИИ расходует кредиты ИИ), прочитать документ пространства (`get_doc`).
- **Автоматизировать**: показать открытые автоматизации и агентов (`list_exposed_actions`), протестировать автоматизацию вхолостую (`run_automation`).
- **Поручать**: запустить агента ИИ (`run_agent`, ожидание не более примерно 100 секунд) и отслеживать состояние его последних запусков (`get_run_status`).

Каждый инструмент обращается к REST API с вашим токеном: сервер не открывает никакого дополнительного доступа.

## Ресурсы и промпты

Сервер также публикует три ресурса для чтения и три готовых промпта.

| Тип | Имя | Содержимое |
|---|---|---|
| Ресурс | `tblflow://workspaces` | Доступные пространства (не более 30) |
| Ресурс | `tblflow://bases/{baseId}` | Таблицы базы |
| Ресурс | `tblflow://tables/{tableId}` | Поля таблицы |
| Промпт | `summarize_table` | Описать таблицу и извлечь из неё ключевые цифры, не изменяя её |
| Промпт | `audit_data_quality` | Найти пустые поля и вероятные дубликаты, ничего не исправляя |
| Промпт | `add_rows_safely` | Добавить записи после проверки схемы и только с вашего согласия |

## Разрешения и выбор пространств

При подключении TblFlow показывает экран «запрашивает доступ к вашей учётной записи». Он перечисляет запрошенные разрешения с такими подписями:

| Разрешение | Отображаемая подпись |
| --- | --- |
| Чтение (по умолчанию) | Читать ваши данные (пространства, таблицы, записи, документы) |
| Запись | Создавать и изменять записи |
| Удаление | Удалять записи (корзина) |
| Схема | Создавать таблицы и поля |
| Запуск | Тестировать автоматизации вхолостую и запускать агентов, которые вы открыли |

Затем выберите пространства и базы, доступные приложению. Отмеченное пространство включает все его базы. Если приложение не проверено TblFlow, экран это указывает («Приложение не проверено»): разрешайте доступ, только если вы сами начали подключение, и проверьте показанный хост перенаправления.

**Чтение** включено по умолчанию; **запись**, **удаление**, **схема** и **запуск** — необязательные опции. Удаление включает восстановление из корзины. Импорт CSV в существующую таблицу требует записи; импорт, который создаёт таблицу, требует схемы. Ваши существующие права в TblFlow применяются к каждому запросу: Claude никогда не может сделать больше, чем можете вы.

## Открыть доступ к автоматизации или агенту

Автоматизацию или агента можно запустить из Claude, только если их владелец **открыл** к ним доступ. Сейчас это делается через API: `PUT /api/base/:baseId/mcp-exposure`. Переключатель в интерфейсе появится позже.

## Из терминала

[CLI TblFlow](/ru/docs/cli) также предоставляет локальный MCP-сервер (`tblflow mcp serve`) для клиентов, которые запускают процесс на вашем компьютере. Он также используется для импорта CSV и экспорта таблицы из командной строки.

## Отзыв доступа

Удалите коннектор в настройках Claude: Claude перестанет получать доступ к вашим данным TblFlow.

## Решение проблем

- **Ошибка авторизации**: переподключите коннектор, затем проверьте, что пространство или база входят в число выбранных вами, что нужное разрешение (запись, удаление, схема или запуск) включено и что ваши права в TblFlow это позволяют.
- **Агент не запускается**: в базе должен быть настроен ИИ, а агент должен быть открыт его владельцем.
- **`run_automation` ничего не меняет**: это тестовый прогон вхолостую на примерах данных. Никакие данные не изменяются.

## Данные и конфиденциальность

Содержимое разговоров не журналируется: сохраняются только вызванный инструмент, время, длительность и статус. Результаты инструментов передаются ассистенту (Claude), чтобы он мог ответить на ваш запрос. Подробности — в [политике конфиденциальности](/ru/privacy) и на [странице MCP-сервера](/ru/mcp).
