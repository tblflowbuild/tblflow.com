Таблица TblFlow — это настоящая таблица PostgreSQL. Поле — это настоящий столбец. Поэтому эта страница полезна, даже если вы никогда не выходите из интерфейса: то, что вы выбираете здесь, и есть в базе данных.

## Семейства полей

В меню **Тип** доступны 28 типов полей, к которым добавляются два пункта: **Подстановка** и **Условная подстановка**. Типы не зависят от вашего тарифа.

**Простые значения** — Однострочный текст, Длинный текст, Число, Дата, Флажок, Рейтинг, Email, Телефон, URL. Они хранят то, что вы ввели, и ничего больше. Email, Телефон и URL требуют корректного формата.

**Длительности** — Длительность, которая отображается как 1:30, 1:30:00 или 1ч 30м, и Отслеживаемая длительность, которая засекает время, потраченное на каждую строку, для каждого человека.

**Отслеживаемая длительность.** Ячейка показывает общее время в часах и минутах; опция поля **Показывать секунды** добавляет секунды. В ячейке ничего не вводится: дважды щёлкните по ней (или нажмите Enter), либо откройте карточку, чтобы перейти к таймеру. **Запустить** начинает период, **Остановить** завершает его; показанный итог увеличивается каждую секунду, пока период идёт, а значение поля обновляется при остановке. Периоды перечислены по участникам, с указанием их начала. Каждый может удалять только свои периоды (**Удалить этот период**), и итог пересчитывается. На одного человека, одну строку и одно поле приходится только один активный период. Запуск и остановка таймера требуют права на изменение записей; при роли с правом только на чтение итог и периоды остаются видимыми, но кнопки не будет.

**Ограниченные значения** — Одиночный выбор, Множественный выбор, Пользователь. Варианты задаются на уровне поля.

**Связи** — Связанная запись, Подстановка, Сворачивание, Условная подстановка, Условное сворачивание. См. ниже.

**Вычисляемые** — Формула (более 200 функций), Автонумерация, ID строки, Время создания, Время последнего изменения, Кем создано, Кем изменено. Их не вводят вручную.

**Активные** — Вложение, Кнопка, Поле ИИ, Canvas. Поле ИИ генерирует содержимое ячейки на основе других полей. Поле Canvas создаёт по одному документу на строку в библиотеке документов.

**Форматы.** Валюта и Процент — не отдельные типы: это форматы типа **Число**, как **Кольцо** и **Полоса**, то есть два способа показать значение. Аналогично **Дата** и **Дата и время** — два варианта настройки типа **Дата**.

Основное поле таблицы, которое идентифицирует каждую запись, поддерживает только часть типов: например, не поддерживаются Вложение и Связанная запись.

## Связывание двух таблиц

Поле **Связанная запись** создаёт связь между двумя таблицами: один-к-одному, один-ко-многим, многие-к-одному или многие-ко-многим. Связь может быть односторонней или двусторонней (**Создать поле обратной связи в связанной таблице**), а также вести в другую базу. После того как связь создана:

- **Подстановка** показывает поле из связанной таблицы (название компании в строке контакта);
- **Сворачивание** агрегирует связанные записи функцией **СУММ** или **СЧЁТ** (сумма сделок аккаунта, количество задач проекта).

**Условная подстановка** и **Условное сворачивание** не требуют связи: вы выбираете таблицу, а затем условия, которые фильтруют её записи (сумма сделок со статусом «Выиграна»).

Эти поля пересчитываются при изменении исходных данных.

## Формулы

Формулы задаются на уровне поля и применяются ко всем строкам. Функции делятся на шесть групп: числовые, текстовые, логические, даты и времени, массивы и системные. Формула может читать поля Подстановка и Сворачивание, но не может напрямую обращаться к полю другой таблицы.

```
IF(
  AND({Статус} = "Выиграна", {Сумма} > 10000),
  "Ключевой клиент",
  "Стандарт"
)
```

Формула не может иметь побочных эффектов: запись в другую таблицу или сетевой вызов невозможны. Для этого нужна [автоматизация](/ru/docs/automations).

## Значение по умолчанию и проверка

В панели поля **Значение по умолчанию** заполняет новые строки. Это доступно для типов Однострочный текст, Длинный текст, Число, Длительность, Телефон, Флажок, Пользователь, Одиночный выбор и Множественный выбор. Для типа Дата вместо этого предлагается **Заполнять текущей датой**.

**Правила проверки значений поля** — это два переключателя:

- **Только уникальные значения**: для типов Однострочный текст, Длинный текст, Число, Длительность, Дата, Email, Телефон и URL;
- **Обязательное**: для этих же типов, а также для выборов, Пользователя, Рейтинга, Отслеживаемой длительности, Вложения и Связанной записи. Этот параметр меняется при редактировании существующего поля, а не при его создании.

Ни один из переключателей не применяется к полю типа Подстановка.

## Что получается в Postgres

Каждая база — это схема PostgreSQL, каждая таблица — физическая таблица, каждое поле — столбец. Владелец базы может открыть **Доступ к Postgres только для чтения** на странице **Конструктор** базы и затем читать данные через `psql`, ORM или инструмент BI. Этот доступ даёт только право чтения: любая запись выполняется через TblFlow. На облачном тарифе он доступен только в тарифе Enterprise. См. [API и разработчики](/ru/docs/api-developers).

## Ограничения, которые стоит знать

- Переименование поля меняет его название, но не ссылку, которую используют формулы: она опирается на внутренний идентификатор поля, поэтому ничего не ломается.
- Смена типа поля конвертирует существующие значения. Если конвертация занимает время или затрагивает поля связей, окно **Подтвердите изменение поля** сначала показывает затронутые поля.
- Удаление поля открывает окно со списком полей, которые от него зависят. Удалённое поле попадает в корзину таблицы, откуда его можно восстановить вместе со значениями в течение срока хранения. См. [Импорт, экспорт и корзина](/ru/docs/import-export-trash).
