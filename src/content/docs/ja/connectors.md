コネクターは、TblFlowを外部サービスに接続します。接続できるのは、アカウント（Gmail、Slackなど）、キーで利用するAPI、またはPostgreSQLデータベースです。接続後は、フィールド、テーブル、自動化、エージェントからコネクターを利用できます。

## 見つける場所

ベース内で**自動化**を開き、**コネクター**タブを選択します。表示は2種類あります。

- **自分のコネクター**：すでに接続済みのアカウント、API、データベース；
- **見つける**：追加できるコネクター。検索と、カテゴリ（メッセージング、CRM、生産性など）で絞り込めます。

**AIで作成**ボタンを使うと、APIのドキュメントからコネクターを作成できます。このページでは説明しません。

## 接続する

### アカウント（OAuth）

**見つける**で、サービスの**+**ボタンをクリックします（ツールチップ「接続」とサービス名が表示されます）。サービスのウィンドウが開き、アカウントの許可を求められます。アカウントを見分けやすいように**アカウント名**を指定できます。その後、コネクターのパネルで**再接続**と**接続を解除**が使えます。接続を解除すると、再接続するまで、そのアカウントを使っている処理（自動化、フィールド、エージェント）が止まります。

サーバーにサービス用のOAuthアプリがない場合、そのサービスは**未設定（管理者）**に表示されます。その場合、スペースの管理者が接続ウィンドウの**詳細設定**欄に、組織のOAuthアプリを登録できます。

### キーで使うAPI

APIコネクターは、**見つける**の**カタログ**セクションにあります。APIコネクターは、まず**インストール**し、次に**接続**します。キーを貼り付け、アカウントのアドレスを求められた場合はそれも入力します。TblFlowは、キーが応答するかをすぐに確認します。

**使用するアカウント**の設定では、スペース全体で使う**共有アカウント**と、**ユーザーごとのアカウント**から選べます。共有アカウントを選ぶと、すべての呼び出しが1つのアカウントを通ります。このアカウントは、スペースの管理者が接続します。

### PostgreSQLデータベース

**PostgreSQL**コネクターは、既存のデータベースのテーブルを読み取り専用で読みます。書き込みは一切送信されません。

## 操作

コネクターのパネルには、**できること**が一覧表示されます。各操作は、次の3つの種類のいずれかに属します。

| 種類 | 意味 |
|---|---|
| **読み取り** | 値をもとに1件のデータを読む |
| **一覧表示** | 項目のリストを返す |
| **実行** | サービス側で何かを作成、変更、送信する |

**テスト**ボタンを使うと、パネルから操作を試せます。操作は、次の4か所で利用できます（**利用箇所**セクション）：接続されたフィールド、同期されたテーブル、自動化（**操作を呼び出す**ステップ）、またはエージェント。エージェントは、操作をツールとして呼び出せます。

カタログからインストールしたコネクターでは、**書き込みを許可**の設定が初期状態で無効になっています。無効の場合、サービス側で作成、変更、削除を行う操作はどこからでも（自動化、ボタン、エージェント）拒否されます。読み取りは引き続き行えます。

## テーブルへの同期

同期されたテーブルは、サービスの一覧を取り込み、その後も最新の状態に保ちます。一覧の各項目が1行になります。

1. コネクターを有効にし、そのパネルの**利用箇所** → **同期されたテーブル**を開きます。
2. ベースを選び、**同期されたテーブルを作成**を選びます。
3. **コネクター**と**一覧**（項目のリストを返す操作）を選びます。**プレビュー**には最初の項目が表示されます。
4. **フィールド**（種類：テキスト、長文テキスト、数値、チェックボックス、日付、リンク、メール）を選び、**一意のID**を指定します。一意のIDは、同期のたびに各項目を見つけ出すために使われます。
5. **同期**を設定します：15分ごと、1時間ごと、6時間ごと、1日ごと、または手動。
6. **消えた項目**の扱い（**行を保持**または**行を削除**）、**項目の最大数**、**モード**を選び、**テーブルを作成**を押します。

**増分**モードは、前回の同期以降に変更された項目だけを読み直します。リスト全体の読み直しは、初期状態では7日ごとです。このモードは、コネクターがそのリストに対して宣言している場合にのみ受け付けられます。**完全**モードは、毎回リスト全体を読み直します。追加の設定がない場合、読み取りは5,000件で止まります。設定できる最大値は50,000件です。同期されたテーブルのフィールドは100個までです。上限によって読み取りが止まった場合は、その旨のメッセージが表示されます。

テーブルの**同期**メニューには、状態の表示、**今すぐ同期**、**すべて再同期**、**同期を停止**があります（テーブルと行は残ります）。

テーブルは初期状態では読み取り専用です。**APIへ変更を送り返す**オプションでは、**ベースの管理者が承認した後**または**変更のたびに自動的に**を選べます。このオプションには、コネクターで書き込みが許可されていることが必要です。

## 自動化のトリガー：「コネクターに新しい項目が現れたとき」

[自動化](/ja/docs/automations)では、**コネクターに新しい項目が現れたとき**トリガーを使うと、リストに新しい項目が現れるたびに、その項目ごとに1回ずつ自動化が起動します。

- コネクター、ID を持つ項目があるリスト、そのパラメーター、そして**確認**の頻度（15分、1時間、6時間、1日）を選びます。
- 最初の読み取りでは、すでにある項目を記録するだけで、何も起動しません。その後に現れた項目だけが自動化を起動します。
- 項目のフィールドは `{{item.<パス>}}` で読み取ります。
- 1回の読み取りで起動する実行は最大50回、読み取るページは最大5ページです。

### キーで使うAPI

| コネクター | できること | 必要なもの |
|---|---|---|
| Make | 組織、チーム、シナリオ、その状態とブループリントを読む（読み取り専用） | Make APIトークン（スコープ `scenarios:read` と `teams:read`）とゾーンのアドレス |
| n8n | ワークフローとその実行履歴を読む（n8n Cloudのインスタンス） | n8n APIキーとインスタンスのアドレス |
| HubSpot | 連絡先、企業、取引を読み取り、検索、作成、更新し、関連付ける | HubSpotのプライベートアプリのトークン |

Make、n8n、HubSpotは、[プロセスマップ](/ja/docs/process-map)にも情報を提供します。

### ClickUp（まだ「見つける」には表示されていません）

ClickUpのコネクターは存在しますが、実際のアカウントでの検証がまだ続いています。そのため**見つける**には表示されず、インターフェースからインストールするボタンもありません。公開されるまでは、日常的な利用には頼らないでください。

ClickUpの**個人トークン**（`pk_`で始まる）で接続します。接続ガイドには、トークンの生成場所が記載されています。ClickUpで、アバター、**設定**、**アプリ**の順に開き、**APIトークン**セクションを確認してください。このトークンにはスコープがありません。お客様の権限で動作し、アクセスできるすべてのワークスペースで使えます。アクセスを制限したい場合は、必要なスペースだけに権限を持つゲストアカウントからトークンを生成してください。

| 種類 | 操作 |
|---|---|
| **一覧表示** | ワークスペース。ワークスペースのスペース。スペースのフォルダー。フォルダーのリスト。フォルダーに入らず、スペース直下にあるリスト。リストのタスク。リストのメンバー |
| **読み取り** | 1つのタスク。カスタムフィールドと、必要に応じてサブタスクを含む |
| **実行** | リストにタスクを作成。タスクの変更またはアーカイブ（送信されたフィールドだけが変わります。カスタムフィールドはここでは変更されません）。タスクへのコメント |

実行に当たる3つの操作は書き込みです。カタログのその他のコネクターと同様に、**書き込みを許可**の設定が無効の間は拒否されます。リストのタスクは100件ずつのページで読み取られ、初期状態では新しいものから順に並びます。

TblFlowは、ClickUpへの呼び出しを間隔を空けて行います。同時に2件まで、2回の呼び出しの間は最低600ミリ秒あけます。これにより、ClickUpの最も低価格なプランに適用される、トークンごとに毎分100リクエストという上限を下回ったままになります。

**コネクターに新しい項目が現れたとき**トリガー（上記参照）は、**リストのタスクを一覧表示**操作で動作します。ClickUpのリストに新しいタスクが追加されるたびに、自動化が起動します。

## 必要な権限

| 操作 | スペースのロール |
|---|---|
| コネクターを使う、自分のアカウントを接続する | 全ロール |
| コネクターを作成、編集する | オーナー、作成者、編集者 |
| カタログからインストールする | オーナー。インストールが自由な場合は作成者も可 |
| コネクターを削除する | オーナー、作成者 |

カタログの管理方法はスペースで設定します：**自由（スペースのオーナーと作成者）**または**スペースの管理者の承認が必要**。後者の場合、他のメンバーは**インストールを依頼**を使います。

同期されたテーブルを作成するには、ベースでテーブルを作成する権限が必要です。ロールの権限の詳細は[権限とロール](/ja/docs/permissions)を参照してください。

## 呼び出し上限

各プランは、APIコネクターへの実際の呼び出しを月ごとに制限します（キャッシュから返された応答は数えません）：無料 1,000、Essential 50,000、チーム 500,000。詳しくは[プランと上限](/ja/docs/plans-limits)を参照してください。
