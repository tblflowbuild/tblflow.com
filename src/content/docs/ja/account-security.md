このページでは、**個人アカウント**に関することを説明します。サインイン、プロフィール、個人の設定、クイック検索、データのエクスポート、アカウントの削除が対象です。スペース全体に適用される設定は、[スペースの設定](/ja/docs/space-settings)にあります。

## サインインする

サインイン画面には**パスワード**の入力欄がありません。サインインの方法は3つあります。最初の2つは常に表示され、3つ目はインスタンスの設定によって異なります。

| 方法 | 使い方 |
|---|---|
| パスキー | **パスキーでサインイン**をクリックし、お使いの端末の認証方法で確認します。 |
| メールのサインインリンク | **または、メールでサインイン**の下にメールアドレスを入力し、**メールでサインインリンクを送信**をクリックします。 |
| 外部サインイン | **または、次で続行**の下からプロバイダーを選びます。GitHub、Google、OIDCのいずれかです。インスタンスで有効になっているプロバイダーだけが表示されます。 |

### パスキー

パスキー（passkey）は、Face ID、Touch ID、Windows Hello、またはセキュリティキーを使います。**最初のサインインの後**に、プロフィールから（後述）追加します。

### メールのサインインリンク

TblFlowは、お使いのメールアドレスにサインインリンクと6桁のコードを送信します。メールには、リンクの有効期限が10分であることが記載されています。リンクを開くか、**6桁のコード**の欄にコードを入力して**サインイン**をクリックします。**リンクを再送信**で、もう一度送信されます。

- この方法が使えるのは、すでにアカウントを持つメールアドレスだけです。未登録のアドレスでも、画面の表示は登録済みのアドレスの場合と同じになりますが、メールは送信されません。これは、どのアドレスがアカウントを持っているかを明かさないための仕様です。アカウントは登録画面から作成してください。
- 送信のリクエストには間隔があります。画面には、次のリクエストまでの待ち時間（秒数）が表示されます。
- 誤ったコードを何度も入力すると、数分間サインインがロックされます。
- インスタンスで不正アクセス防止のための確認（ボット対策）が使われている場合は、入力欄の下に表示されるので、送信の前に確認を完了してください。

インスタンスの設定でこの方法を無効にできます。その場合、画面には「このインスタンスではパスワードなしのサインインを利用できません」と表示されます。

### 外部サインインとSSO

**GitHub**、**Google**、**OIDC**のボタンをクリックすると、各プロバイダーに移動します。これらのボタンは、インスタンスで設定されている場合にだけ表示されます。**OIDC**ボタンは、インスタンス全体で設定されたOpenID Connectプロバイダーに対応するものです。スペースの設定では変更できません。

## アカウントを作成する

サインイン画面から**サインアップ**を開きます。フォームでは次の項目を入力します。

- メールアドレス
- 利用規約とプライバシーポリシーへの同意（必須）
- メールで送られる**認証コード**（インスタンスが求める場合）
- **招待コード**（インスタンスが待機リストで運用している場合）。待機リストに登録する場合は、**待機リストに参加**のリンクを使います。

パスワードは作成されません。設定によっては、インスタンスで新規登録が停止されていることもあります。その場合、登録のタブは、スペース、ベース、または共有ビューへの招待リンクからのみ利用できます。

## マイプロフィール

アバターのメニューを開き、**設定**を選びます。このウィンドウには個人の設定がまとめられています。**マイアカウント**、**マイ通知**、**コネクター**、**個人アクセストークン**、**マイスキル**、**OAuthアプリ**です。現在のスペースの設定も、アクセス権があればこのウィンドウに表示されます。

**マイアカウント**タブ（見出しは**マイプロフィール**）には次の設定があります。

| 設定 | 詳細 |
|---|---|
| アバター | **アバターを変更**で画像を選びます。 |
| 表示名 | TblFlowで表示される名前です。入力欄を離れると保存されます。 |
| **名**と**姓** | 姓は大文字で保存されます。 |
| テーマ | **ライト**、**ダーク**、**システム**から選びます。 |
| 言語 | 下記を参照してください。 |
| **ベースの表示** | スペース内のベース一覧の表示形式です。**自動**、**カード**、**リスト**から選びます。 |
| **ベース内の表示** | ベースを開いたときの表示形式です。選択肢は同じ3つです。 |
| **操作モード** | **マウスモード**、**タッチモード**、**システムに従う**から選びます。この項目は、タッチとマウスの両方に対応した端末でのみ表示されます。 |

### インターフェースの言語

**言語**の選択欄には10の言語があり、加えて**Default**（ブラウザーの言語）を選べます。

中文、English、Italiano、Français、Deutsch、日本語、Русский、Українська、Türkçe、Español (Latinoamérica)

選択内容はアカウントに保存され、その後ページが再読み込みされます。

### アカウントのセキュリティ

**アカウントのセキュリティ**セクションには、次の項目があります。

**メールアドレス。** **メールアドレスを変更**をクリックすると新しいアドレスを入力でき、**コードを送信**で認証コードが送られます。**確認**をクリックすると変更が確定します。セッションは閉じられ、サインイン画面に戻ります。この操作には、過去15分以内にパスキーまたはバックアップコードを使ってサインインしている必要があります。そのため、必要になる前にパスキーを登録しておいてください。

**パスキー。** **パスキーを追加**をクリックすると、お使いの端末で登録が始まり、キーの名前を入力するよう求められます。一覧の各キーには**削除**ボタンがあります。アカウントにパスキーかバックアップコードがすでにある場合、パスキーの追加や削除には、直近の強力な認証が必要です。まだ何もないアカウントでは、最初のパスキーをそのまま登録できます。

**バックアップコード。** **生成**をクリックすると、1回限りの使用になる10個のコードが作成されます。これらのコードは、パスキーを紛失したときの代わりになりますが、サインインには使えません。表示されるのは一度だけです。すぐに**コピー**または**ダウンロード**で保存してください。**再生成**をクリックすると、コードの一式がすべて置き換わり、古いコードは使えなくなります。残りのコード数も表示されます。

**TblFlowサポートのアクセス。** スイッチをオンにすると、お問い合わせの際にサポートがお客様の代わりにサインインできるようになります。初期状態ではオフです。表示される説明によると、各セッションは最長30分で、別途合意がない限り読み取り専用です。また、理由とともに記録されます。いつでも取り消せます。

**データの取り扱い。** スイッチは2つあります。

- **個人データの処理を制限する（GDPR 第18条）**：必須ではない自動処理を凍結します。データは何も削除されません。アカウントは引き続き使えます。
- **コンテンツのAI処理に異議を唱える（GDPR 第21条）**：インポートしたドキュメントは、AI機能によるインデックス作成と読み取りの対象外になります。ドキュメントは引き続き保存され、ダウンロードできます。

処理の制限にはAI処理も含まれます。その場合、2つ目のスイッチはロックされます。

このセクションには、許可したサードパーティ連携の一覧も表示され、取り消すことができます。コネクター、個人アクセストークン、OAuthアプリには、それぞれ専用のページがあります。詳しくは[コネクター](/ja/docs/connectors)と[APIと開発者](/ja/docs/api-developers)を参照してください。

## 通知

### 通知センター

ベル型のアイコンには、未読の通知の数が表示されます。パネルには2つのリストがあります。未読と既読（**既読**）です。また、**すべて既読にする**ボタンと、続きを読み込む**もっと見る**があります。

### メール

**マイ通知**では、メールで受け取る内容を設定します。段階は3つです。

| 段階 | 内容 |
|---|---|
| **すべての通知** | メンションとコメントに加え、プラットフォームからのメッセージも届きます。インポートやエクスポートの完了、自動化やAI生成の失敗、クォータと請求に関する通知が対象です。 |
| **メンションとコメントのみ** | セル内やコメントであなたに言及された場合、またはコメントが投稿された場合だけ届きます。 |
| **メールなし** | 通知はアプリ内でのみ表示されます。 |

Slack、Teams、Google Chatへの転送は個人の設定ではなく、スペースの設定です。詳しくは[スペースの設定](/ja/docs/space-settings)を参照してください。

## クイックアクションと検索

**Ctrl+K**（Macでは**⌘+K**）で、**クイックアクション**パレットが開きます。虫めがねのボタンからも開けます。同じショートカットで閉じられます。

- **ベース内**：パレットには、そのベースのテーブル、アプリ、自動化が表示されます。作成のアクションや、**AIアシスタントを開く**（入力したテキストがあれば**アシスタントに質問**）、テーマの選択、設定を開く操作も利用できます。
- **スペース内**：入力すると、スペース内でサーバー側の検索が行われます。結果としてベース、テーブル、ビュー、ダッシュボード、自動化、アプリが表示され、10件ずつのページに分かれています。**もっと読み込む**で続きを表示できます。結果をクリックするとその項目が開きます。権限があれば、**ベースを作成**のアクションも表示されます。

提示されるアクションは、お使いの権限によって異なります。許可されていない操作は表示されません。

**テーブル内**では、**Ctrl+F**（Macでは**⌘+F**）でツールバーの検索欄にフォーカスできます。**グローバル検索**（日付、チェックボックス、ボタン以外のすべてのフィールドが対象）または**フィールド別検索**を利用できます。詳しくは[ビューとフィルター](/ja/docs/views-and-filters)を参照してください。

## データをエクスポートする

**マイアカウント**タブの下部にある**アーカイブをダウンロード**で、zipファイルが作成されます。このファイルには、プロフィールの項目を含む`profile.json`、スペース内でお客様が所有する各ベースのフォルダー（レコードと添付ファイル）が含まれます。サードパーティサイトの認証情報のメタデータがある場合は、それも含まれます。関連するパスワードはエクスポートされません。

## アカウントを削除する

**マイアカウント**タブの下部にある**アカウントを削除**をクリックすると、確認画面が開きます。この操作は取り消せません。

1. まず、所属しているスペースから退出してください。スペースのメンバーである間、またはゴミ箱に入ったスペースのオーナーや作成者である間は、削除が拒否されます。その場合、画面に該当するスペースの一覧と各スペースへのリンクが表示されます。
2. 確認欄に`DELETE`と入力します。入力内容が一致するまで**削除**ボタンは押せません。
3. サーバーは、15分以内に行われたサインインを求めます（パスキーまたは直近のバックアップコードがある場合）。該当しない場合は、サインインし直してからやり直してください。

その後、次の処理が行われます。

- メールアドレスは置き換えられ、名前は削除され、アバターは初期設定のものに置き換えられます。
- アクセストークン、連携アカウント、パスキー、バックアップコード、通知、エージェントとの会話は削除されます。
- コメントの内容は消去されます。
- 共有ベースのレコードは残ります。これらはチームのものであり、お客様は「Deleted User」という名前でのみ表示されます。
