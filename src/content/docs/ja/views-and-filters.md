ビューはテーブルを読むための方法です。データはコピーされません。1つのテーブルに好きな数だけビューを作成でき、それぞれに独自のフィルター、並べ替え、表示フィールドを設定できます。

## ビューの種類

ビュータブの右にある **+** ボタンから、6種類のビューを選べます。新しいビューには、その種類の名前（「カンバン」「カレンダー」など）が付きます。同じ名前が既にある場合は、番号が続きます。

| 種類 | 表示内容 | 固有の設定 |
|---|---|---|
| **グリッドビュー** | レコードを行、フィールドを列で表示します。 | 行の高さ、非表示フィールド、条件付き書式。 |
| **ギャラリービュー** | レコードを1枚ずつカードで表示します。 | カバーフィールド、**カードをカスタマイズ**。 |
| **カンバンビュー** | カードを列に積み重ねて表示します。 | **積み重ねるフィールドを選択**、**空の積み重ねを非表示**、**カードをカスタマイズ**。 |
| **カレンダービュー** | レコードを日付に配置して表示します。 | **カレンダーの設定**：開始日、終了日、タイトル、色のフィールド。 |
| **ガントビュー** | 時間軸上のバーでレコードを表示します。 | **設定**：開始、終了、タイトル、依存関係、色のフィールド。 |
| **フォームビュー** | テーブルへの入力フォームを表示します。 | フィールド、ページ、表示条件、テーマカラー。 |

補足：

- **カレンダーとガント**には日付フィールドが必要です。ガントには少なくとも1つの日付または日時フィールドが必要です。バーはマウスでドラッグして移動でき、スケールは **日**、**週**、**月**、**四半期** に切り替えられます。
- **ガント**：依存関係フィールドは通常、**別のレコードへのリンク**フィールドです。**週末**と**クリティカルパス**のオプションはツールバーで設定します。循環依存があると警告が表示され、その場合クリティカルパスが不完全になることがあります。
- **カレンダーとガント**には **予定未設定** パネルがあり、日付のないレコードが一覧表示されます。レコードをビューにドラッグすると、日付を設定できます。
- **フォーム**：表示するフィールドを選び、改ページを追加し、条件を満たした場合にのみフィールドを表示できます。**必須**に設定されたフィールドはフォームから削除できません。フォームの公開方法は [共有と公開](/ja/docs/sharing-publishing) を参照してください。
- **AIでビューを生成**：同じ **+** メニューで目的のビューを説明すると、TblFlowが種類、フィルター、並べ替え、列を含めてビューを作成します。

## ビューの管理

ビューのタブを右クリックすると、メニューが開きます。

| 操作 | 必要な権限 |
|---|---|
| **名前の変更**、**ロック** / **ロック解除**、**共有** | ビューの編集 |
| **複製** | ビューの作成 |
| **削除** | ビューの削除 |
| **CSVをダウンロード**（グリッドビュー） | テーブルのエクスポート |
| **お気に入りに追加** / **お気に入りから削除** | 特別な権限は不要 |

オーナー、作成者、エディターのロールは、ビューを作成、編集、削除できます。コメンターと閲覧者のロールはできません。詳しくは [権限とロール](/ja/docs/permissions) を参照してください。

**ロック**されたビューには錠のアイコンが表示されます。表示を変更するには、後述の個人モードに切り替える必要があります。

## フィルター、並べ替え、グループ化、非表示

これらの設定はビューのツールバーにあります。

**フィルター。** **条件を追加** で行を追加し、フィールド、演算子、値を指定します。**条件グループを追加** で条件をネストでき、その深さは最大3階層です。レコードが **すべての条件に一致** するか、**いずれかの条件に一致** するかを選べます。

- 演算子はフィールドの種類によって異なります。「次と等しい」「次を含む」「空である」「次より大きい」「次のいずれか」などがあります。
- ユーザーフィールドでは、値 **自分（現在のユーザー）** を選ぶと、そのビューを見ている人が自動的に対象になります。
- 日付フィールドでは、相対的な値（今日、昨日、先週、今月、過去または未来の日数）か、正確な日付でフィルターできます。
- 無効になった条件（例：リストの選択肢が削除された場合）は無視され、警告が表示されます。

**並べ替え。** **並べ替え** では複数のフィールドを指定でき、**別の並べ替えを追加** でさらに追加できます。**レコードを自動で並べ替える** を有効にすると、順序は常に最新に保たれます。このオプションが有効な間は、行の手動ドラッグ＆ドロップは無効になります。

**グループ化。** **グループ化** で行をフィールドごとにまとめ、**サブグループを追加** で階層を1段追加できます。

**非表示フィールド。** このリストでは、フィールドを削除せずにビューの中で隠せます。**すべて表示** と **すべて非表示** で一括操作できます。メインフィールドは、非表示にも削除にもできません。

**行の高さ。** 短い、中くらい、高い、非常に高いの4段階から選べます。

**条件付き書式。** ルールで、セルまたは行全体の色（文字色または背景色）を変更できます。**すべてのビューに適用** を選ぶと、そのルールがテーブルの他のビューにも広がります。

**クイック切り替え。** グリッドでは **自分に割り当て** と **完了を非表示** を、ビューのフィルターに追加できます。ビューの設定自体は変更されません。これらは、テーブルにユーザーフィールドがある場合、または「完了」を示すフィールド（チェックボックス、または完了を意味する選択肢を持つリスト）がある場合にのみ表示されます。

## 協同モードと個人モード

既定では、ビューは **協同** モードです。フィルター、並べ替え、グループ化、非表示フィールド、行の高さはビューに保存されます。誰かが変更すると、そのビューを開いているすべてのメンバーに変更が表示されます。

ツールバーの **個人** ボタンで、この動作が変わります。個人モードでは、設定は自分だけに適用されます。設定はサーバーではなくブラウザに保存されます。個人モードを終了するときは、変更を破棄するか（**終了を確認**）、全員に適用するか（**終了して同期**）を選べます。後者には、ビューの編集権限が必要です。

ロックされたビューの表示を調整できるのも、この個人モードだけです。

## レコード詳細

各行は詳細画面として開きます。レコードのすべてのフィールドを表示するページです。**位置** メニューで、中央、サイドパネル、全画面のいずれかを選べます。**前のレコード** と **次のレコード** のボタンで、行を移動できます。

詳細のヘッダーには、直接リンクを共有するための **レコードのURLをコピー** ボタンと、履歴を表示するボタンがあります。そのメニューでは、**テーブルで表示**、**印刷 / PDF**、**レコードを複製**、**レコードを削除** を選べます。

ビューで非表示にしたフィールドは、**N 個の非表示フィールドを表示** からいつでも開けます。

**レイアウト。** **レイアウト** メニューで、フィールドの順序、幅（半分または全幅）、折りたたみ可能なセクションを設定します。名前付きのレイアウトは複数作成できます。変更はビューのすべてのユーザーに適用されます。

**履歴。** 履歴には変更内容が、**変更前** と **変更後** の値とともに一覧表示されます。時間範囲、フィールド、ユーザーで絞り込みでき、**表で表示** または **文章で表示** に切り替えられます。テーブルのメニューにある **テーブルのレコード履歴** は、オーナー、作成者、エディターのロールのみが利用できます。

## コメント

詳細の **コメント** タブで、レコードのディスカッションを開きます。コメントにはリンク、画像、メンション、絵文字、音声メッセージ、画面クリップを含められます。通知は **すべてのコメント** か、自分に関係するものだけかを選べます。**アクティビティ** タブではレコードの履歴を表示します。このタブは、レコードを編集できるロールにのみ表示されます。

コメントの投稿にはコメントの権限が必要です。オーナー、作成者、エディター、コメンターのロールは投稿できますが、閲覧者は投稿できません。

**音声メッセージと画面クリップ。** コメントエディターのツールバーには **音声メッセージを録音** と **画面クリップを録画** があります。ブラウザがマイクまたは画面へのアクセスを求めます。拒否された場合は「マイクまたは画面へのアクセスが拒否されました。」と表示されます。録音中は経過時間が表示され、**停止** で録音を終えると、その音声またはクリップが送信されてコメントに添付されます。最長時間は音声メッセージが5分、画面クリップが3分です。上限に達すると、録音は自動的に停止します。

**AIアシスタントに依頼する。** コメントで **@** を入力し、**IA**（メンション一覧では **AIアシスタント**）を選びます。ベースのアシスタントが行を読み取り、「AIアシスタント」名義のコメントで返信します。アシスタントは初回の呼び出し時にベース内に作成されます。レコードやテーブルを検索して読み取り、テーブルの構造と行のアクティビティを確認し、ナレッジベースを参照できます。レコードの作成や変更も可能ですが、書き込みのたびに人による承認が必要です（[AIエージェント](/ja/docs/ai-agents) の **書き込みの承認** を参照してください）。返信は4,000文字で切り詰められます。AIの利用枠と権限は、@IAでメンションした人のものが適用されます。AIが利用できない場合（利用枠の上限に達した、処理への異議が出ている）、返信のコメントにその旨が表示されます。ベースで「AIアシスタント」エージェントが無効になっている場合、@IAには応答しません。

## ダッシュボード

ベースのサイドバーにある **ダッシュボード** から、グラフや指標をまとめたページを開けます。ページには **あなたのダッシュボード** が一覧表示されます。これは、ベース内のテーブルのうち、グラフブロック形式のビューです。新しく作成するには、**AIで作成** を選ぶと、自由な依頼を入力してチャットを開始できます。**テンプレート** セクションには3つの出発点があります：**プロジェクト管理**、**CRM**、**プロセスマップのコスト**。この項目は、ベースを閲覧する権限があれば表示されます。

## ホワイトボード

ホワイトボードは、テーブルと並ぶベース内のリソースです。構造化する前にアイデアを練るための自由なスペースです。サイドバーの **+** メニューの **その他のリソース** から、**新しいホワイトボード** で作成します。ベースを編集する権限（オーナーと作成者のロール）が必要です。

- ツール：**選択**、**付箋**、**テキスト**、**枠**、**レコード**、**ペン**、**画像**、**コメント**。**レコード** ツールは、既存のレコードにリンクしたカードをボードに配置します。
- 6つの開始用テンプレート：ブレインストーミング、プロジェクトの範囲定義、プロセス、データベース設計、振り返り、組織図。空のキャンバスから始めることもできます。
- **このボードを活用** は、選択した内容をテーブルのレコードに変換します。枠の場合は、テーブルの作成も提案します。作成の前に、その提案を承認できます。
- **エクスポート** で、PNG 画像または PDF 文書を出力します。

## グラフ

グラフは、テーブルの横にある **プラグインパネル** に配置します。ビューを作成する必要はありません。パネルのボタン（パズルのピースのアイコン）は、テーブルのツールバーにあります。

1. パネルを開きます。空の場合は **プラグインパネルを作成** をクリックし、名前を付けて **確定** で保存します。
2. パネルで **プラグインを追加** をクリックし、**グラフ** の横の **インストール** をクリックします。
3. 最初の画面 **データクエリの設定** で、グラフのデータを取得するクエリを組み立てます。ブロックは **From**、**Select**、**Where**、**Group by**、**Aggregation**、**Order by**、**Limit**、**Offset**、**Join** です。**保存** をクリックします。
4. 次に、右側のパネルで **グラフの種類** を選びます：**棒**、**折れ線**、**円**、**エリア**、**表**。

設定はグラフの種類によって異なります。

- **棒、折れ線、エリア**：**X軸**、**Y軸**、**別の系列を追加**、**系列の内訳を追加**、**積み上げ**、**目標線**、**範囲**（**最小**、**最大**）、**線のスタイル**、**Y軸の位置**；
- **円**：**ディメンション**、**メジャー**、**合計を表示**；
- 対応している種類では、**グラフに値ラベルを表示** と **凡例を表示**。

各グラフのヘッダーには **展開**、**複製**、**名前の変更**、**削除** があります。**名前の変更** と **削除** にはテーブルの編集権限が必要です。**クエリを更新** ボタンでクエリの設定を開き直し、**クエリを再読み込み** でデータを再取得します。
