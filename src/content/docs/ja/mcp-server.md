TblFlowの公式MCPサーバーを使うと、Claudeが会話の中からお客様のデータを扱えるようになります。Streamable HTTPによるリモートMCPサーバーで、認証はOAuth 2.1（いつものTblFlowのサインイン）です。[REST API](/ja/docs/api-developers)と同様に、無料プランから利用できます。

サーバーのURL：`https://app.tblflow.com/mcp`

## 接続する

### Claude（Web、デスクトップ、モバイル）

1. **設定 → コネクタ → カスタムコネクタを追加**を開きます。
2. URL `https://app.tblflow.com/mcp` を入力します。
3. TblFlowのアカウントでサインインします。
4. アクセスを許可するスペースとベースを選び、続いて権限を選びます。

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 27のツール

サーバーは27のツールを公開します。用途別に次のとおりです。

- **探す**：スペースとベースの一覧（`list_workspaces`）、テーブルのビュー（`list_views`）、スペースのメンバー（`list_collaborators`、メールアドレスは含みません）を取得します。
- **理解する**：ベースのスキーマを説明し（`describe_base`）、スペースのプロセスマップを読み取ります（`get_process_map`）。
- **読む**：レコードを一覧表示、絞り込み、読み取ります（`list_records`、`get_record`）。1回の呼び出しで最大100件です。
- **計算する**：テーブルの統計を計算します（`aggregate_records`）。フィルターとグループ化を使えますが、すべての行を読み込むことはありません。関数は、件数、空の値、入力済みの値、ユニークな値、最小値、最大値、合計、平均、空・入力済み・ユニークの割合、最も古い日付と最も新しい日付です。
- **検索する**：ナレッジグラフを、セマンティック検索と全文検索で検索します（`search_knowledge`）。
- **作成・変更する**：レコードを作成・変更します（`create_records`、`update_records`）。1回の呼び出しで最大50件です。
- **インポートする**：2MB以下のCSVを、既存のテーブルまたは新しいテーブルにインポートします（`import_csv`）。既定では、最初の呼び出しは列、推定された型、行数だけを表示し、何も書き込みません。
- **削除・復元する**：レコードまたはフィールドを削除します（`delete_records`、`delete_field`）。プレビューを表示したうえで、明示的な確認を求めます。テーブルのゴミ箱を一覧表示し、削除したものを復元することもできます（`list_trash`、`restore_records`）。
- **構造を作る**：テーブルを作成し（`create_table`）、フィールドを作成し（`create_field`）、名前と説明、そしてCanvasフィールドの場合はそのオプションを変更します（`update_field`）。フィールドの型は変更できません。
- **ドキュメントとCanvasの概要**：レコードの概要を読み取り（`get_canvas_doc`）、変更し（`update_canvas_doc`）、Canvasフィールドの概要の生成を開始できます（`generate_canvas_docs`。1回の呼び出しで最大25行まで。AIモードではAIクレジットを消費します）。スペース内のドキュメントを読むこともできます（`get_doc`）。
- **自動化する**：公開されている自動化とエージェントを一覧表示し（`list_exposed_actions`）、自動化をテスト実行します（`run_automation`）。
- **委任する**：AIエージェントを起動し（`run_agent`。最大約100秒待機します）、直近の実行の状態を確認します（`get_run_status`）。

各ツールは、お客様のトークンを使ってREST APIを呼び出します。サーバーが追加で開くアクセスはありません。

## リソースとプロンプト

サーバーは、読み取り専用のリソースを3つと、すぐに使えるプロンプトを3つ公開しています。

| 種類 | 名前 | 内容 |
|---|---|---|
| リソース | `tblflow://workspaces` | アクセスできるスペース（最大30件） |
| リソース | `tblflow://bases/{baseId}` | ベース内のテーブル |
| リソース | `tblflow://tables/{tableId}` | テーブル内のフィールド |
| プロンプト | `summarize_table` | テーブルを説明し、主要な数値を取り出します。テーブルは変更しません |
| プロンプト | `audit_data_quality` | 空のフィールドと、重複の可能性があるレコードを見つけます。何も修正しません |
| プロンプト | `add_rows_safely` | スキーマを確認したうえでレコードを追加します。お客様の同意がある場合にのみ行います |

## 権限とスペースの選択

接続時、TblFlowは「お客様のアカウントへのアクセスを要求しています」という画面を表示します。要求されている権限が次の表示名で一覧されます。

| 権限 | 表示名 |
|---|---|
| 読み取り（既定） | お客様のデータを読み取る（スペース、テーブル、レコード、ドキュメント） |
| 書き込み | レコードを作成・変更する |
| 削除 | レコードを削除する（ゴミ箱） |
| スキーマ | テーブルとフィールドを作成する |
| 実行 | 公開した自動化をテスト実行し、エージェントを起動する |

続いて、アプリがアクセスできるスペースとベースを選びます。スペースにチェックを入れると、そのスペースのすべてのベースが含まれます。アプリがTblFlowによって検証されていない場合、画面に「アプリは未検証です」と表示されます。接続を自分で開始した場合にのみ許可し、表示されるリダイレクト先のホストを確認してください。

**読み取り**は既定で有効です。**書き込み**、**削除**、**スキーマ**、**実行**はオプションです。削除にはゴミ箱からの復元も含まれます。既存のテーブルへのCSVインポートには書き込みが必要で、テーブルを作成するインポートにはスキーマが必要です。TblFlowの既存の権限は各リクエストに適用されます。Claudeがお客様にできる以上のことを行うことは決してありません。

## 自動化またはエージェントを公開する

自動化またはエージェントは、所有者が**公開**した場合にのみ、Claudeから起動できます。現在、公開はAPIで行います：`PUT /api/base/:baseId/mcp-exposure`。画面上のスイッチは準備中です。

## プランごとの上限

| プラン | 1分あたりのリクエスト数 |
|---|---|
| 無料 | 60 |
| Essential | 120 |
| チーム | 300 |
| Enterprise | 600 |

## ターミナルから使う

[TblFlow CLI](/ja/docs/cli)にも、ローカルのMCPサーバー（`tblflow mcp serve`）があります。お使いのPC上でプロセスを起動するクライアント向けです。コマンドラインからCSVをインポートしたり、テーブルをエクスポートしたりする用途にも使えます。

## アクセスを取り消す

Claudeの設定でコネクタを削除します。削除すると、ClaudeはTblFlowのデータにアクセスできなくなります。

## トラブルシューティング

- **認可エラー**：コネクタを再接続します。そのうえで、スペースまたはベースが選択したものに含まれていること、必要な権限（書き込み、削除、スキーマ、実行のいずれか）が有効であること、そしてTblFlowの権限でアクセスが許可されていることを確認します。
- **エージェントが起動しない**：ベースにAIが設定されている必要があり、エージェントは所有者によって公開されている必要があります。
- **`run_automation` が何も変更しない**：テスト実行であり、サンプルデータを使います。データは変更されません。

## データとプライバシー

会話の内容は記録されません。記録されるのは、呼び出されたツール、時刻、所要時間、状態だけです。ツールの結果は、お客様のリクエストに答えるためにアシスタント（Claude）に渡されます。詳細は[プライバシーポリシー](/ja/privacy)と[MCPサーバーのページ](/ja/mcp)に記載しています。
