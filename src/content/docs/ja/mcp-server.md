TblFlowの公式MCPサーバーを使うと、Claudeが会話の中からお客様のデータを扱えるようになります。Streamable HTTPによるリモートMCPサーバーで、認証はOAuth 2.1（いつものTblFlowのサインイン）です。REST APIと同様に、無料プランから利用できます。

サーバーのURL：`https://app.tblflow.com/mcp`

## 接続する

### Claude（Web、デスクトップ、モバイル）

1. **設定 → コネクタ → カスタムコネクタを追加**を開きます。
2. URL `https://app.tblflow.com/mcp` を入力します。
3. TblFlowのアカウントでサインインします。
4. アクセスを許可するスペースとベースを選び、続いて権限を選びます。

### Claude Code

```bash
claude mcp add --transport http tblflow https://app.tblflow.com/mcp
```

## 13のツール

サーバーは13のツールを提供しており、次のように分類されます。

- **探索する**：スペースとベースを一覧表示します。
- **把握する**：ベースのスキーマを説明します。
- **読む**：レコードの一覧表示、絞り込み、読み取りを行います。
- **検索する**：knowledge graphを、セマンティック検索と全文検索で調べます。
- **作成・編集する**：レコードを作成、編集します。
- **削除する**：レコードを削除します。まずプレビューを表示し、そのあと明示的な確認を行います。レコードはごみ箱に移動します。
- **構造を作る**：テーブルまたはフィールドを作成します。
- **自動化する**：自動化をトリガーします。
- **任せる**：AIエージェントを実行します。

## 権限とスペースの選択

接続時に、アクセスを許可するスペースとベース、および権限を選びます。**読み取り**はデフォルトで有効で、**書き込み**、**削除**、**スキーマ**、**トリガー**はオプションです。リクエストのたびに、お客様のTblFlowでの既存の権限が適用されます。Claudeがお客様にできる以上のことを行うことはありません。

## 自動化やエージェントを公開する

自動化やAIエージェントは、所有者が**公開**している場合にのみ、Claudeからトリガーできます。現在、公開はAPIで行います：`PUT /api/base/:baseId/mcp-exposure`。画面上のスイッチは今後追加される予定です。

## プランごとの制限

| プラン | 1分あたりのリクエスト数 |
| --- | --- |
| 無料 | 60 |
| Pro | 120 |
| Business | 300 |
| Enterprise | 600 |

## アクセスを取り消す

Claudeの設定でコネクタを削除すると、ClaudeはTblFlowのデータにアクセスしなくなります。

## トラブルシューティング

- **認可エラー**：コネクタを再接続し、そのスペースまたはベースが選択したものであること、必要な権限（書き込み、削除、スキーマ、トリガー）が有効であること、お客様のTblFlowでの権限で許可されていることを確認してください。
- **エージェントが起動しない**：ベースでAIが設定されている必要があり、エージェントが所有者によって公開されている必要があります。
- **`run_automation` で何も変更されない**：サンプルデータによるドライランだからです。データは一切変更されません。

## データとプライバシー

会話の内容はログに記録されません。保存されるのは、呼び出されたツール、時刻、所要時間、ステータスのみです。ツールの結果は、ご依頼に応えるためにアシスタント（Claude）に渡されます。詳細は[プライバシーポリシー](/ja/privacy)と[MCPサーバーのページ](/ja/mcp)をご覧ください。
