エージェントは、ベースに紐づく実行者です。指示、使用できるツールのセット、メモリを持ち、既定では書き込みのたびにご承認を待ちます。

エージェントのプロファイルは5つのタブで構成されます：**指示**、**作業**、**能力**、**ナレッジ**、**メモリ**。

## モデルを選ぶ

プロバイダーとそのキーは、スペースごとに **スペースのAI設定** で設定します。変更できるのはスペースのオーナーだけです。キーは保存時に暗号化され、保存後は平文で表示されなくなります。

利用可能なプロバイダーは、OpenAI、Anthropic、Google、Azure、Cohere、Mistral、DeepSeek、xAI、Amazon Bedrock、OpenRouter、OpenAI互換の任意のエンドポイントです。OllamaおよびLM Studio経由のローカルモデルも利用できます。追加したキーは、インスタンスのキーに加算されます。ただし **インスタンスのモデルを既定で使用** を無効にした場合は除きます。

エージェントのプロファイルにある **モデル** セレクターで、専用のモデルを割り当てられます。未指定の場合、エージェントはAI設定の既定のチャットモデルを使います。

## 範囲を定める

エージェントの範囲は3つの要素で決まります。

- **そのベース。** エージェントは、別のベースのテーブルを読み書きできません。ベースに含まれないテーブルは拒否されます。
- **そのツール。** **能力**タブには、エージェントが実行できるアクションが一覧表示されます。無効化されたツールはモデルに提示されないため、モデルは呼び出せません。レコード、テーブル、コメントに関するツールの大半は既定で有効です。外部にアクセスする、またはファイルを生成するツールは既定で無効で、1つずつ有効にします。対象は、Webでの検索、Excel、Word、PowerPoint、PDFの生成、スキルやコードの実行、メール、Slack、Microsoft Teams、GitHub、カレンダー、Drive、SharePoint、ブラウザースキルの再生です。他のエージェントへの委任は、オーケストレーターのエージェントに対してのみ既定で有効です。
- **その接続。** コネクタで接続したアカウントがエージェントに使われます。人が起動しない場合（スケジュール、トリガー）は、作成者のアカウントが使われます。エージェントにMCPサーバーを追加することもできます。

エージェントが到達できる範囲を絞るには、必要のないツールを外してください。サポートの振り分けを行うエージェントに、メールの送信やレコードの削除は必要ありません。

## 書き込みの承認

**書き込みの承認** の設定は、エージェントごとに既定で有効です。有効な間、実際に効果のあるツールは実行されず、エージェントは待機して承認を求めます。対象は特に、レコードの作成、変更、削除、テーブル・フィールド・ビューの作成、コメント、メールやメッセージの送信、自動化の起動、コードやスキルの実行、メモリへの書き込みです。

回答は **承認** または **拒否**（任意の理由を添えられます）で行います。保留中のリクエストは、ベースの **承認** ページに表示され、**保留中の承認を表示** リンクからも開けます。回答がない場合、リクエストは7日後に期限切れとなり、そのアクションは実行されません。

この設定は、エージェントのエラーの傾向を確認してから無効にしてください。無効にすると、エージェントはすべての書き込みを単独で行います。この設定はテーブルごとには切り替えられません。

## メモリ

**メモリ** タブでエージェントのメモリを有効または無効にできます。メモリには2つの項目があります。

| 項目 | 内容 |
| --- | --- |
| 最近 | 直近の作業における短期的な記憶。7日間保持されます。最新50件が保持され、タスク開始時には最新5件がエージェントに提供されます |
| 設定 | 人間が与えた指示。キーと値の形式で、タスクごとにエージェントに提供されます |

エージェントが情報を記憶すると、そこからエンティティと関係がスペースのグラフに抽出されることがあります。エージェントは **メモリを検索** ツールでこのグラフを照会します。つまり、メモリは会話の履歴ではありません。やり取りは別途、履歴に保存されます。

**記憶を表示** で、エージェントの記憶の一覧を開けます。ベースの編集者は記憶を **修正** または **削除** できます。エージェントが誤った情報を覚えた場合は、指示を直すのではなく、そのエントリを修正してください。

## スキル

スキルとは、名前の付いた指示のブロックで、スクリプトを伴う場合もあります。エージェントはそれを使えます。個人用（アカウント）のものと、スペース内で共有されたものがあります。エージェントが利用できるスキルは、作成者のものとスペースのものです。いずれも既定で無効で、**能力**タブでエージェントごとに有効にします。スキルのスクリプトの実行は **スキルのスクリプトを実行** ツールを経由し、このツールも既定で無効です。

## トリガー

**作業**タブには、エージェントがいつ実行されるかが表示されます。

| トリガー | 動作 |
| --- | --- |
| メンション | レコード上で自分がメンションされたとき、エージェントが分析して返信します（スイッチ） |
| ダイレクトメッセージ | 送信されたメッセージに、エージェントが返信します（スイッチ） |
| **エージェントを実行** | 手動で実行します |
| スケジュール | 定期的な時刻、またはカスタムのcron式で実行します。15分未満の間隔は既定で拒否されます |
| 自動化 | テーブルのレコードの作成時または変更時に実行します |
| 受信Webhook | HTTP呼び出しによってエージェントを起動します |

レコードのトリガーは、書き込みの承認が無効のときにしか動作しません。承認が必要な間は非アクティブのままです。人に確認を求められない自動起動の場合、承認を得る手段がないためです。スケジュールとWebhookは承認と併用でき、承認のリクエストは承認ページに届きます。

## 上限

エージェントの実行は、手動、スケジュール、トリガーのいずれで起動されたかにかかわらず、月単位で計上されます。

| プラン | 月あたりのエージェント実行数 |
| --- | --- |
| 無料 | 100 |
| Essential | 5,000 |
| チーム | 50,000 |
| Enterprise | 無制限 |

セルフホストでは、これらの上限は適用されません。AIの利用には、プランごとの別の制限も適用されます。[自動化](/ja/docs/automations)の上限は別途計上されます。

## 履歴

各実行は会話として保存され、エージェントのツール呼び出し、そのパラメーター、結果を含みます。会話の履歴は、エージェントのチャットから確認できます。

## ベストプラクティス

- エージェント1つにつき目的は1つ。「CRMを管理する」エージェントは失敗が散漫になりますが、役割を絞った3つのエージェントなら失敗の原因が読み取りやすくなります。
- 導入初期は書き込みの承認を有効にしておき、エージェントのエラーの性質が分かってから無効にしてください。
- エージェントのミッションに必要なツールだけを有効にしてください。
