このページでは、空のアカウントから、チームと共有できるベースを作るまでを案内します。所要時間は約5分です。

## 1. ベースを作成する

スペースで**ベースを作成**をクリックします。ベースはテーブル、自動化、エージェントをまとめるもので、各テーブルは独自のビューを持ちます。内部では、各ベースが専用のPostgreSQLスキーマです。

ウィンドウが開き、どのようなアプリを作りたいかを尋ねられます。

- **アプリを説明する** — 管理したいものを入力し（「研修センターのコース時間割を管理するツール」など）、**アプリを生成**をクリックします。AIがスキーマ、ビュー、インターフェース、自動化を提案し、ステップごとに確認できます。スペースにAIが設定されていない場合、ボタンは**AIを接続して生成**に変わり、設定画面に移動します。[AIチャット](/ja/docs/ai-chat)を参照してください。
- **空のベースから始める** — AIによる生成なしでベースを作成します。テーブルは後から追加します。

まだベースがないスペースでは、**テンプレートから始める**こともできます。「**プロジェクト管理**」テンプレートはTblFlowに付属するギャラリーにあり、プロジェクト、タスク（サブタスクと依存関係あり）、スプリント、担当者のテーブルを作成します。カンバン、ガント、カレンダーのビューと、ステータスごとにグループ化して合計を表示する**ダッシュボード**ビューも含まれます。さらに、タスクの「完了日」を設定または消去する自動化が2つあります。プロジェクト1件、スプリント1件、サンプルのタスク5件も用意されています。これらは編集するか削除してください。別のベースからエクスポートした**.tbl**ファイルは、**インポート**でスペースに読み込み直せます。[インポート、エクスポート、ゴミ箱](/ja/docs/import-export-trash)を参照してください。

### テーブルを追加する

ベースのサイドバーにある追加ボタンから、次の項目を選択できます。

- **新しいテーブル** — フィールドを手動で定義します。
- **AIで作成** — テーブルを説明すると、プレビューが表示されます。**作成**をクリックするまで、何も作成されません。
- **他のソースから追加** — CSV、TSV、Excelファイルのインポート、またはファイルへのリンク（**Lien(URL)**）。フィールドの型はデータから推測されます（**フィールドの型を自動選択**オプション）。インポート前に修正できます。表計算ソフトからコピーしたセルは、グリッドビューに貼り付けることもできます。

## 2. フィールドを構成する

フィールドの型は、ただのスプレッドシートとベースを分けるものです。ここを正しく設定しておくことが大切です。残りの要素（数式、フィルター、自動化）はこれに依存します。

| ニーズ | 使う型 |
| --- | --- |
| 固定された値の集合から1つを選ぶ | 単一選択 |
| 別のテーブルへのリンク | 別のレコードへのリンク |
| リンク先テーブルの値 | ルックアップ |
| リンクされたレコードの集計 | ロールアップ |
| 行ごとの計算 | 数式 |

フィールドの型はお使いのプランに左右されません。[テーブルとフィールド](/ja/docs/tables-and-fields)を参照してください。

## 3. 2つ目のビューを開く

ビューはテーブルの読み取り方であり、コピーではありません。ビューを切り替えてもデータは複製されません。

ステータスフィールドがあるテーブルでは、そのステータスで積み上げた**カンバン**ビューを追加します。日付があるテーブルには、**カレンダー**または**ガント**ビューを追加します。フィルター、並べ替え、グループは各ビューに保存されます。デフォルトでは、ビューは共同編集用です。同僚が「期限切れの自分の案件」のフィルターを変更すると、全員にその変更が表示されます。**個人**ボタンを使うと、設定を自分だけに限定できます。[ビュー、フィルター、レコード](/ja/docs/views-and-filters)を参照してください。

## 4. チームを招待する

ベースのサイドバーにある**招待**ボタンで共有画面を開きます。これはベースを編集できるロールのユーザーのみ利用できます。各ユーザーにはロールが割り当てられます。ベースでは、作成者、編集者、コメント投稿者、閲覧者のいずれかです（オーナーのロールはスペースレベルで設定します）。ベースまたはテーブルにカスタムロールを設定することもできます。ビューを外部に公開または共有するには、[共有と公開](/ja/docs/sharing-publishing)を参照してください。[権限とロール](/ja/docs/permissions)も参照してください。

編集はリアルタイムの共同作業です。2人が同じテーブルを同時に編集でき、各参加者の現在のセルはグリッド内に表示されます。
