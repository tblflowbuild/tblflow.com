このページでは、空のアカウントから、チームで作業できるベースまでを案内します。所要時間は5分です。

## 1. ベースを作成する

ダッシュボードから**新しいベース**を選びます。ベースはワークスペースで、複数のテーブル、独自のビュー、自動化、エージェントを持ちます。内部では、専用のPostgreSQLスキーマです。

始め方は3つあります。

- **空のテーブル** — フィールドを自分で定義します。
- **インポート** — CSV、Excel、またはスプレッドシートからそのまま貼り付けます。フィールドの型はデータから推定され、確定する前に修正できます。
- **自然な言葉での説明** — 管理したいもの（「連絡先、企業、案件を持つ営業パイプライン」など）を説明すると、アシスタントがスキーマを提案します。提案を承認するまで、何も作成されません。

## 2. フィールドの型を正しく選ぶ

フィールドの型こそが、データベースとスプレッドシートを分けるものです。少し時間をかけてください。数式、フィルタ、自動化はすべて型に依存します。

| 必要なもの | フィールドの型 |
| --- | --- |
| 固定の選択肢から1つの値 | 単一選択 |
| 別のテーブルへのリンク | リンクレコード |
| リンク先のテーブルから取得した値 | ルックアップ |
| リンクされたレコードの集計 | ロールアップ |
| 行ごとの計算 | 数式 |

28種類すべての型を、セルフホストを含むすべてのプランで利用できます。

## 3. 2つ目のビューを開く

ビューはテーブルの見方であり、コピーではありません。ビューを切り替えても、何も複製されません。

ステータスのフィールドがあるテーブルには、そのステータスでグループ化した**カンバン**ビューを追加します。日付のあるテーブルには、**カレンダー**や**ガント**ビューを追加します。フィルタ、並べ替え、グループ化はビューに属します。同僚の「期限切れの自分の項目」ビューが、あなたのビューを変えることはありません。

## 4. チームを招待する

右上の**共有**を選びます。権限はベース単位（オーナー、編集者、コメント投稿者、閲覧者）で設定でき、テーブルごと、フィールドごとに絞り込めます。

編集はリアルタイムの共同作業です。2人が同時に同じテーブルで作業でき、カーソルと変更がすぐに表示されます。
