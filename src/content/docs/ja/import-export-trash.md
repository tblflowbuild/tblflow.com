このページでは、TblFlowに取り込むもの、TblFlowから書き出すもの、そして操作を元に戻す方法をまとめて説明します。

## ファイルをインポートする

TblFlowは、**CSV**、**TSV**、**Excel**の3つの形式をインポートできます（拡張子は`.xlsx`、`.xls`、`.xlsm`）。ローカルのファイルは、拡張子で形式を判断します。お使いの端末から送信するExcelファイルは、5 MBを超えることはできません。

新しいテーブルとしてインポートする方法と、既存のテーブルに行を追加する方法の2つがあります。

### 新しいテーブルとしてインポートする

1. ベースのサイドバーで **+** メニューを開き、**他のソースから追加**の項目から、**データをインポート**を選びます。
2. **ローカルファイル**タブ（ファイルを領域にドラッグします）または**リンク（URL）**タブ（ファイルのアドレスを貼り付けます）を選びます。
3. **データのプレビュー**に、検出された列が表示されます。**AIで分析して実装**を有効にできます。AIが列名とフィールドの型を提案するので、次の手順でそのまま使うか修正するかを選べます。
4. インポートの設定を行います。
   - **最初の行をヘッダーとして使用**；
   - **フィールドの型を自動選択**；
   - 各フィールドの名前と型。列を取り除く場合は**インポートしない**を選びます。
   - **メインフィールド**；
   - **データをインポート**（オフにすると構造だけを作成します）；
   - Excelのブックの場合は、シートごとに設定します（**シート名**）。
5. **インポート**をクリックし、警告メッセージで**確認して続行**をクリックします。

フィールド名は一意でなければならず、空にはできません。インポートは成功か失敗で終わります。状態はテーブルの右上に表示され、結果は通知で知らされます。インポートの途中では、フィールドを変更しないでください。

### 既存のテーブルにインポートする

テーブルのメニューを開き、**データをインポート**から**CSVファイル**または**Microsoft Excel**を選びます。ファイルの各列をテーブルのフィールドに対応づけます。**インポートから最初の行を除外**をオンにすることもできます。行は既存の行に追加されます。

この操作には、テーブルへのインポート権限が必要です。オーナーとクリエイターのロールが対象です。インポートで新しいテーブルを作成するには、テーブルを作成する権限が必要です。

### 制限とエラー

インポートは、お使いのプランのテーブルあたりの行数上限の対象です。無料は5,000行、Essentialは100,000行、チームは1,000,000行、Enterpriseは上限なしです。上限を超えると、インポートは「行数の上限に達しました」というメッセージとともに停止します。[プランと上限](/ja/docs/plans-limits)を参照してください。

そのほかに起こりうるエラーは、有効な範囲外の日付、空欄のままの**必須**フィールド、**一意の値**しか受け付けないフィールドの重複、タイムアウトです。

### そのほかのインポート方法

- **グリッドに貼り付け。** 表計算ソフトのセルをコピーして、グリッドのビューに貼り付けます。貼り付けた内容がテーブルの範囲を超える場合、TblFlowはレコードを追加するかどうかを尋ねます。既存の行を上書きする前には、確認を求めます。
- **コマンドライン**：`tblflow import --new-table` でCSVファイルを送信します。[CLI](/ja/docs/cli)を参照してください。
- **エージェントから**：MCPサーバーは`import_csv`ツールを提供します。[MCPサーバー](/ja/docs/mcp-server)を参照してください。

## エクスポートする

### テーブルをCSVで書き出す

テーブルのメニューで**csvをダウンロード**を選びます。グリッドのビューでは、同じ選択肢がタブのメニュー（右クリック）にあります。その場合、エクスポートはそのビューから行われ、ビューのフィルターと並べ替えを引き継ぎます。テーブルを読み取れるすべてのロールがエクスポートできます。

### ベース全体を書き出す

スペースのベース一覧で、ベースのメニューに**エクスポート**があります。**エクスポート**のウィンドウには**レコードを含める**オプションがあります。オフにすると、構造と設定だけがエクスポートされます。

1. **エクスポートを開始**をクリックします。時間がかかる場合があります。ウィンドウは閉じても構いません。
2. データの準備ができると、通知が届きます。
3. `.tbl`ファイルを**ダウンロード**します。

再インポートするには、スペースのページに`.tbl`ファイルをドロップします。「インポートするには.tblファイルをドロップしてください」と表示されます。別のベースへのリンクフィールドは、エクスポートでは1行のテキストに変換されます。

ベースをエクスポートまたは複製するには、ベースを編集する権限が必要です。オーナーとクリエイターのロールが対象です。

## 元に戻す・やり直す

ツールバーの**元に戻す**と**やり直す**のボタン（Ctrl またはCmd + Z、Ctrl またはCmd + Shift + Z）は、テーブルでの直前の操作を取り消したりやり直したりします。レコードを編集できる場合に有効です。

対象になるのは、セルの入力と貼り付け、レコードの作成・削除・並べ替え、フィールドの作成・削除・変換、ビューの作成・変更・削除です。

取り消しの履歴は、ユーザーごと、テーブルごとに保持されます。既定では、直近の200件の操作を24時間保持します。新しい操作を行うと、やり直しのスタックは空になります。

**レコードの履歴**は別の機能です。誰が何を変更したかを、変更前と変更後の値とともに記録します。[ビュー、フィルター、フォーム](/ja/docs/views-and-filters)を参照してください。

## ゴミ箱

テーブル、ベース、レコード、フィールド、ビューを削除しても、すぐには消去されません。削除された項目はゴミ箱に移動し、そこから**復元**できます。

| ゴミ箱 | 場所 | 中身 |
|---|---|---|
| **テーブルのゴミ箱** | テーブルのメニュー | 削除されたビュー、フィールド、レコード |
| ベースの**ゴミ箱** | ベースのサイドバーの**ゴミ箱**アイコン | 削除されたテーブル、アプリ、自動化、エージェント、ブラウザースキル |
| スペースの**ゴミ箱** | スペースのメニュー | そのスペースから削除されたベース |
| **スペースのゴミ箱** | スペースの切り替え | 削除されたスペース、ベース、テーブル（3つのタブに分かれています） |

**種類**、**削除者**、**日付**の列には、何が、誰によって、いつ削除されたかが表示されます。テーブルのゴミ箱では、**開始**と**終了**のフィルターで期間を絞り込めます。**スペースのゴミ箱**のページには、**完全に削除**もあります。

- **保持期間。** 既定では30日です。この期間を過ぎると、自動的なパージによって項目は完全に削除されます。ベースとスペースのゴミ箱には、お使いのインスタンスに適用されている期間が表示されます（「過去N日間に削除されたもの」）。
- **空にする**は、確認のあとにベースのゴミ箱の内容を完全に削除します。
- **容量。** ゴミ箱にあるデータも、レコードと添付ファイルの使用量に含まれます。
- **復元の順序。** 親がゴミ箱に入っている項目は復元できません。先にベースを復元し、それからそのテーブルを復元してください。
- **フィールド。** フィールドを復元すると、その値も戻ります。対象のレコードが多い場合があるため、進行状況のウィンドウが表示されます。

テーブルのゴミ箱を閲覧・復元できるのは、オーナー、クリエイター、エディターのロールだけです。コメンターと閲覧者のロールはアクセスできません。[権限とロール](/ja/docs/permissions)を参照してください。

## テーブルまたはベースを複製する

**テーブル。** テーブルのメニューで**複製**を選びます。コピーに名前を付け、**レコードを含める**で行をコピーするかどうかを選びます（既定でオンです）。テーブルを読み取り、そのベースにテーブルを作成できる必要があります。オーナーとクリエイターのロールが対象です。

**ベース。** ベースのメニューで**複製**を選び、続けて**ベースを複製**を選びます。複製先のスペースと、レコードを複製するかどうかを選びます。変更履歴とコラボレーターは複製されません。

## テンプレートから始める

テンプレートは、すぐに使えるベースです。テンプレートを選ぶと、**テンプレートからベースを作成**のウィンドウが開き、複製先のスペースを尋ねられます。**レコードを複製**がオンなら、ベースにはテンプレートのサンプルデータが入ります。オフなら、構造だけがコピーされます。選んだスペースにベースを作成できる必要があります。

ご自身のテンプレートを公開するには、[共有と公開](/ja/docs/sharing-publishing)を参照してください。
